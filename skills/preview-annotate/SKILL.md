# 匿名预览与组件批注

## 作用

本 skill 把前端构建目录发布成一个临时公开链接，并在页面上注入批注层。用户在页面上选组件、写批注。批注保存在本机 JSON 文件中，智能体读取后逐条修改。

| 部件 | 文件 |
|---|---|
| 启停脚本 | `scripts/preview.sh` |
| 静态服务（SPA 回退、注入批注层、批注接口） | `scripts/server.mjs` |
| 批注层（页面内交互） | `scripts/annot.js` |
| 读批注 | `scripts/list.py` |

本 skill 不改项目源码，不进项目的 Git。服务只用 Node 内置模块，没有 npm 依赖。

> **警告**：链接是公开的。任何拿到链接的人都能看页面、写批注、删批注。只把链接发给用户本人或团队。不要用它发布含真实客户数据、令牌或内部接口的构建。
> **注意**：只在用户要求临时链接或批注时启动。用完按第 5 节停止，并删除工作目录。

## 0. 环境要求

| 依赖 | 版本或说明 |
|---|---|
| 系统 | macOS 或 Linux，bash |
| Node.js | 18 或更高。PATH 里没有 `node` 时，脚本会找 `~/.nvm` 下的最新版本 |
| `cloudflared` | 任意近期版本。macOS 运行 `brew install cloudflared`；Linux 从 <https://github.com/cloudflare/cloudflared/releases> 下载 |
| `curl` | 系统自带即可 |
| Python 3 | 只用于 `list.py` 读批注 |

快速隧道不需要 Cloudflare 账号，也不需要登录。

## 1. 启动

1. 构建项目，得到含 `index.html` 的目录（例如 `frontend/dist`）。
2. 选一个项目内已被 Git 忽略的临时目录作为工作目录（例如 `local-artifacts/preview`）。不要用 `/tmp`，因为系统可能清掉 `/tmp`，批注会丢。
3. 运行下面的命令。`S` 是本 skill 目录下的 `scripts`，例如 `~/.claude/skills/preview-annotate/scripts`。

```bash
S=<本 skill 目录>/scripts
bash $S/preview.sh start <构建目录> <工作目录> [端口，默认 4192]
```

脚本最后一行打印 `https://<随机词>.trycloudflare.com`。脚本会等到链接能打开再返回。如果端口已被占用，脚本报错退出，换一个端口再运行。

4. 用 `curl -s -o /dev/null -w '%{http_code}' <链接>/<一个子路由>` 确认返回 200，再把链接给用户。

服务和隧道在后台运行，不依赖当前会话。

## 2. 重新构建后更新

1. 重新构建到同一个构建目录。
2. 运行 `bash $S/preview.sh reload <工作目录>`。脚本只重启服务，隧道不动，因此链接不变。
3. 告诉用户刷新页面。

如果改的是 `annot.js`，不用重启服务。服务每次请求都重新读取它。

## 3. 用户怎么批注（转告用户）

1. 点右下角 **选组件批注**。
2. 移动鼠标，蓝框标出指针下的组件，并显示组件名和尺寸。滚动页面时，蓝框跟随指针下的实际组件。
3. 如果指针落在过小的元素上，按 **↑** 选父级，按 **↓** 回子级。
4. 点击组件。选择模式下点击不触发页面跳转。按 Esc 取消。
5. 写批注，按 **Enter** 保存。按 Shift+Enter 换行。中文输入法选词时的 Enter 不会保存。
6. 保存后右下角提示“已保存”，组件左上角出现橙色编号。
7. 点 **批注列表** 查看本页和全站批注，可以定位、前往或删除。

## 4. 读取并处理批注

```bash
python3 $S/list.py <工作目录>/annotations.json            # 全部
python3 $S/list.py <工作目录>/annotations.json --since 2026-10-22T03:00   # 只看这个时间之后的
```

每条批注含：路由、视口、组件名与尺寸、组件文字、CSS 选择器和批注内容。处理方法：

1. 按页面分组，先合并重复批注（同一选择器、同一内容）。
2. 用选择器和组件文字在源码中找到组件。用截图确认当前样子。
3. 把批注分成两类：单点修改，和需要重新设计的区域。重新设计的区域先给用户方案。
4. 修改、构建、`reload`，然后请用户在同一链接上复查。
5. 已处理的批注不要自行删除，由用户在页面上删除，或在用户同意后清空文件。

## 5. 停止与清理

1. 运行 `bash $S/preview.sh stop <工作目录>`。链接立即失效。
2. 确认批注已处理完，再删除工作目录。

`preview.sh status <工作目录>` 显示进程状态、链接和批注条数。

## 已知限制

- 只托管静态构建，不代理开发服务器，因此没有热更新。改代码后要重新构建再 `reload`。
- 快速隧道没有可用性保证。隧道进程退出后链接失效，重新 `start` 会得到新链接。
- 页面结构变化后，旧批注的选择器可能找不到组件。这时编号按保存时的页面坐标显示。
- 批注层的界面文字是中文。
- 服务最多保存 2000 条批注，单次请求体最大 64 KB。
