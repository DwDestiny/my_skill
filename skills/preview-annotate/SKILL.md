# 匿名预览与组件批注

## 作用

本 skill 把前端构建目录发布成一个临时公开链接，并在页面上注入批注层。用户在页面上选组件、写批注。批注保存在本机 JSON 文件中，智能体读取后逐条修改。

answer-me-with-html 生成的页面走第 6 节：`am serve` 加快速隧道，不注入批注层。

| 部件 | 文件 |
|---|---|
| 启停脚本 | `scripts/preview.sh` |
| 静态服务（SPA 回退、注入批注层、批注接口） | `scripts/server.mjs` |
| 批注层（页面内交互） | `scripts/annot.js` |
| 读批注 | `scripts/list.py` |
| answer-me-with-html 页面的常驻服务与隧道 | `scripts/am-pub.sh` |

本 skill 不改项目源码，不进项目的 Git。服务只用 Node 内置模块，没有 npm 依赖。

> **警告**：链接是公开的。任何拿到链接的人都能看页面、写批注、删批注。只把链接发给用户本人或团队。不要用它发布含真实客户数据、令牌或内部接口的构建。
> **注意**：第 1–5 节的预览只在用户要求临时链接或批注时启动。用完按第 5 节停止，并删除工作目录。第 6 节的 am 页面服务常驻运行，不随任务停止。

## 0. 环境要求

| 依赖 | 版本或说明 |
|---|---|
| 系统 | macOS 或 Linux，bash |
| Node.js | 18 或更高。PATH 里没有 `node` 时，脚本会找 `~/.nvm` 下的最新版本 |
| `cloudflared` | 任意近期版本。macOS 运行 `brew install cloudflared`；Linux 从 <https://github.com/cloudflare/cloudflared/releases> 下载 |
| `curl` | 系统自带即可 |
| Python 3 | 只用于 `list.py` 读批注 |

快速隧道不需要 Cloudflare 账号，也不需要登录。

## 1. 启动

1. 构建项目，得到含 `index.html` 的目录（例如 `frontend/dist`）。
2. 选一个项目内已被 Git 忽略的临时目录作为工作目录（例如 `local-artifacts/preview`）。不要用 `/tmp`，因为系统可能清掉 `/tmp`，批注会丢。
3. 运行下面的命令。`S` 是本 skill 目录下的 `scripts`，例如 `~/.claude/skills/preview-annotate/scripts`。

```bash
S=<本 skill 目录>/scripts
bash $S/preview.sh start <构建目录> <工作目录> [端口，默认 4192]
```

脚本最后一行打印 `https://<随机词>.trycloudflare.com`。脚本会等到链接能打开再返回。如果端口已被占用，脚本报错退出，换一个端口再运行。

4. 用 `curl -s -o /dev/null -w '%{http_code}' <链接>/<一个子路由>` 确认返回 200，再把链接给用户。

服务和隧道在后台运行，不依赖当前会话。

## 2. 重新构建后更新

1. 重新构建到同一个构建目录。
2. 运行 `bash $S/preview.sh reload <工作目录>`。脚本只重启服务，隧道不动，因此链接不变。
3. 告诉用户刷新页面。

如果改的是 `annot.js`，不用重启服务。服务每次请求都重新读取它。

## 3. 用户怎么批注（转告用户）

1. 点右下角 **选组件批注**。
2. 移动鼠标，蓝框标出指针下的组件，并显示组件名和尺寸。滚动页面时，蓝框跟随指针下的实际组件。
3. 如果指针落在过小的元素上，按 **↑** 选父级，按 **↓** 回子级。
4. 点击组件。选择模式下点击不触发页面跳转。按 Esc 取消。
5. 写批注，按 **Enter** 保存。按 Shift+Enter 换行。中文输入法选词时的 Enter 不会保存。
6. 保存后右下角提示“已保存”，组件左上角出现橙色编号。
7. 点 **批注列表** 查看本页和全站批注，可以定位、前往或删除。

## 4. 读取并处理批注

```bash
python3 $S/list.py <工作目录>/annotations.json            # 全部
python3 $S/list.py <工作目录>/annotations.json --since 2026-10-22T03:00   # 只看这个时间之后的
```

每条批注含：路由、视口、组件名与尺寸、组件文字、CSS 选择器和批注内容。处理方法：

1. 按页面分组，先合并重复批注（同一选择器、同一内容）。
2. 用选择器和组件文字在源码中找到组件。用截图确认当前样子。
3. 把批注分成两类：单点修改，和需要重新设计的区域。重新设计的区域先给用户方案。
4. 修改、构建、`reload`，然后请用户在同一链接上复查。
5. 已处理的批注不要自行删除，由用户在页面上删除，或在用户同意后清空文件。

## 5. 停止与清理

1. 运行 `bash $S/preview.sh stop <工作目录>`。链接立即失效。
2. 确认批注已处理完，再删除工作目录。

`preview.sh status <工作目录>` 显示进程状态、链接和批注条数。

服务 24 小时没有收到请求时自动退出，同时停掉隧道，批注文件保留。要改时长，启动前设 `PREVIEW_IDLE_HOURS`（`0` 表示不退出）。原因：2026-11-09 在一台服务器上查到 13 个忘了停的预览，最久的跑了 13 天，共占约 700 MB 内存。

## 6. 发布 answer-me-with-html 页面

answer-me-with-html（下称 am）生成的页面自带「回复」和「标注」，不需要本 skill 的批注层。页面的内容安全策略也会拦下注入的脚本。因此在 `am serve` 前面接一条快速隧道。

> **警告**：链接是公开的。只把链接发给用户本人或团队。`am render` 会列出页面里嵌入的代码文件。页面含私有代码、客户数据或令牌时，先告诉用户，再发链接。

1. 运行 `bash $S/am-pub.sh ensure`。服务已在运行时，脚本立即打印地址。服务没有运行或隧道断了时，脚本重启 `am serve` 和隧道，需要 10–70 秒。
2. 用 `am render` 出页面，输出到 `~/.answer-me-with-html/pages/`（不加 `-o`，或 `-o` 指向这个目录里的文件）。输出里多一行 `link: https://<随机词>.trycloudflare.com/p/<令牌>/<文件名>.html`。
3. 运行 `curl -s -o /dev/null -w '%{http_code}' <link>`，确认返回 200。
4. 把 `link:` 后面的地址给用户。

按页面用途选输出位置：

| 页面用途 | 输出位置 | 改稿后的链接 |
|---|---|---|
| 一次性的回答 | 不加 `-o`。改稿后重新渲染时加 `--replace <上一版路径>` | 每次是新链接 |
| 要多轮修改的页面（方案、计划） | `-o ~/.answer-me-with-html/pages/<项目>-<主题>.html` | 文件名不变，链接不变，用户刷新即可 |

如果页面要存进项目仓库，把草稿（`draft.md`）存在项目里，按上表渲染拿链接，再把页面复制进项目。项目里的位置按该项目 L1 的规定。

读用户反馈：

1. 用户在页面上点「回复」，选好答案、写好评论后复制，贴回对话。智能体按 am skill 第 5 节处理。
2. 回复和标注边输入边存到服务端。用户没贴回时，运行 `bash $S/am-pub.sh replies [文件名]` 读取。

维护：

| 要做的事 | 命令或说明 |
|---|---|
| 看状态 | `bash $S/am-pub.sh status`：进程、地址、页面数、有回复的页面数 |
| 停止 | `bash $S/am-pub.sh stop`。所有链接立即失效 |
| 隧道重启后打开旧链接 | 链接密钥存在 `~/.answer-me-with-html/serve-secret`，`/p/<令牌>/<文件名>` 不变。把旧链接的域名换成 `ensure` 打印的新地址 |
| am 链接返回 404 或 530 | 先 `ss -ltnp | grep ':8765 '` 看端口上是不是 `am serve`。8765 是它的默认端口，别的临时服务不要占，也不要用 `fuser -k` 清这个端口。被占时隧道会把公开链接转到占用它的程序上，要先停掉那个程序，再运行 `ensure` |
| 清理页面 | 先运行 `am clean --dry-run`，把数量告诉用户。用户同意后再运行 `am clean` |

每个链接只能打开一页。服务不列目录，根路径返回 404。`ensure` 用"根路径返回 `Not found`"判断整条链路是通的。

## 已知限制

- 只托管静态构建，不代理开发服务器，因此没有热更新。改代码后要重新构建再 `reload`。
- 快速隧道没有可用性保证。隧道进程退出后链接失效，重新 `start` 会得到新链接。 第 6 节的服务用 `am-pub.sh ensure` 重启。
- 页面结构变化后，旧批注的选择器可能找不到组件。这时编号按保存时的页面坐标显示。
- 批注层的界面文字是中文。
- 服务最多保存 2000 条批注，单次请求体最大 64 KB。
