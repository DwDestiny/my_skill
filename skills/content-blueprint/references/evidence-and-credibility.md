# 证据索引与可信度

方法来源：tyroneross/pyramid-principle 的 source-integrity（Apache-2.0，只取字段与规则）；product-on-purpose 的 master-first（断言编号，页面只引用编号）。

## 1. 证据索引字段

| 字段 | 说明 | 允许值 |
|---|---|---|
| ID | 断言编号 | C001 起，三位数 |
| 原话 | 资料中的原句或原数 | 逐字；超过 50 字可截取并标"节选" |
| 类型 | 三态 | 事实 / 判断 / 缺口 |
| 来源 | 来源名 | 机构、媒体、文件名 |
| 定位 | 在来源里的位置 | 章节号、页码、URL、行号 |
| 日期 | 来源日期 | YYYY-MM-DD；不明写"未注明" |
| 核验日期 | 本次读到的日期 | YYYY-MM-DD |
| 可信度 | 四级 | 高 / 中 / 低 / 未验证 |
| 范围 | 适用边界 | 期间、地域、单位、分母 |
| 反面证据 | 判断类必填 | 与该判断相反的事实或口径 |
| 去向 | 取舍结果 | 主线 / 折叠 / 附录 / 删除 |
| 章节 | 使用位置 | 章节 id，可多个 |

## 2. 可信度四级

| 级别 | 含义 |
|---|---|
| 高 | 政府或官方文件原文；法规原文；一手数据 |
| 中 | 主流媒体转述官方发布；行业协会转载；律所或研究机构评论 |
| 低 | 厂商宣传；自媒体；招聘页；百科；自述数据 |
| 未验证 | 只看到搜索摘要或二手引用，没有读到原文 |

规则：

1. 用户提供且未独立核对的来源，最高到"中"。
2. "自述"（企业自己提供、未经独立验证的数据）标"低"，并在原话后注"自述"。
3. "转载"（协会或媒体转载的官方数据，未对照原文）标"中"，注"转载"。
4. 结构层不得升级可信度：把一条"低"放进标题或摘要，它仍是"低"。
5. 项目已有可信度口径时，沿用项目口径，不另造一套。

## 3. 什么算断言

1. 数字、名称、日期、引文。
2. 评价词：显著、领先、大幅、仅、首个、唯一、成熟。
3. 因果句："因为 A 所以 B"。
4. 比较句："比去年多""高于行业平均"。

"用户输入""公司数据""研究显示"不算来源。

## 4. 三态标记

| 标记 | 条件 | 页面写法 |
|---|---|---|
| 事实 | 有来源与定位 | 断言末尾标"事实"，附来源编号与可信度 |
| 判断 | 基于事实的分析，附依据与反面证据 | 标"判断"，正文写依据；反面证据可折叠 |
| 缺口 | 查过但没有答案 | 标"缺口"，写查过什么、没找到什么 |

一句话里不混两种类型。事实句后另起一句写判断。

## 5. 来源在页面上的表达（交给 A 的要求）

1. 来源用编号上标，点开或悬停显示：来源名 · 日期 · 定位 · 可信度。正文不展开。
2. 可信度用文字标签，可配形状，不只靠颜色。
3. 页面放一次可信度图例。
4. 来源与标记字号 ≥12px，不被动效遮蔽。

## 6. 冲突与口径差异

两个来源数字不一致时：

1. 两条都登记，各自可信度。
2. 蓝图里写"口径差异"，说明差在哪里（统计范围、时间、单位）。
3. 页面主线用可信度高的一条，另一条放折叠。
4. 不取平均，不自己"修正"。
