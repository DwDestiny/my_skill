# 形式选择

先问"这个信息的形状是什么"，再选形式。装饰性的图不选。每张图配一句结论标题。图中数字必须来自证据索引。

## 1. 信息形状到形式

| 信息形状 | 形式 | 蓝图 `form` 值 | 由 A 用什么画 |
|---|---|---|---|
| 单个判断、定义 | 一句话文字 | `text` | HTML |
| 单个当前值，带变化 | 指标磁贴 | `metric` | dataviz |
| 多对象 × 多属性 | 表格 | `table` | HTML 表格 |
| 两三个选项的差异 | 并排对比 | `compare` | HTML grid |
| 有先后、有日期 | 时间线 | `timeline` | diagram-design 或 HTML |
| 数量、趋势、占比（≥3 个数据点） | 数据图 | `chart` | dataviz |
| 有流向、有角色交接、有边界 | 机制图 | `diagram` | artifact-diagramming 或 diagram-design |
| 空间结构、机构运动本身是要讲的内容 | 等轴测交互图 | `figure3d` | anatomy |
| 部件分层关系，不需交互 | 分层或爆炸图 | `exploded` | diagram-design |

## 2. 不画图的判据

1. 一句话说得更快。
2. 去掉图后，读者不需要靠段落硬记空间、顺序、层级关系。
3. 超过约 7 个类别且每类都有含义：用表格。
4. 数据不足 3 个点：用指标磁贴或文字。
5. 概念没有物理对应物：不用 3D。

## 3. 预算（写进蓝图 `budget`，与 A 的 `figures.md` 一致）

| 形式 | 预算字段 | 上限 |
|---|---|---|
| `table` | 行 × 列 | 列 ≤7；行超过 12 加筛选或拆表 |
| `compare` | 列数 × 行数 | 列 ≤3；行 ≤8 |
| `timeline` | 节点数 | ≤8 |
| `metric` | 磁贴数 | 一屏 ≤4；英雄数字 ≤1 |
| `chart` | 序列数、点数 | 序列 ≤4（≥4 必须直接标注）；类别 >7 改表格 |
| `diagram` | 节点、箭头、泳道、层数 | 总览节点 ≤7，细节 ≤9；箭头 ≤10；泳道 ≤4；层 ≤6 |
| `figure3d` | 部件数、读数字数 | 部件 40 到 60；读数 ≤12 字 |
| `exploded` | 部件数 | ≤5 |
| 任何图 | 图内标签字数 | 每标签 ≤12 字 |

超预算时：拆成总览加细节，或改表格。不缩小字号。

## 4. 每个内容块在蓝图里要写的

```
- block: <章节 id>-<序号>
  shape: <信息形状>
  form: <form 值>
  title: <一句结论>
  claims: [C0xx, …]
  budget: <按上表写数值，例如 nodes=6, arrows=7, lanes=3>
  mobile: <手机下怎么放：堆叠 / 横向滚动 / 另出竖图>
  twin: <表格孪生或文字摘要放哪>
```

## 5. 3D 与炫技形式的边界

B 只判断"内容是否需要这种形式"。效果强度、动效、着色由 A 按档位决定。B 在 `notes` 里可写"该图是候选签名时刻"，由 A 采纳或退回。
