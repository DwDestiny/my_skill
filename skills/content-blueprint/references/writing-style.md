# 写法：ASD-STE100 风格简明中文

适用于本 skill 的全部产物和页面上的说明性文字。主标题、副标题、过渡句、按钮、首屏等展示文案另按 `copywriting.md` 写。

## 1. 词

1. 一词一义，一义一词。不为变化而换同义词。
2. 术语以术语表为准（`glossary.md` 或蓝图附录）。新词先登记再用。
3. 不把动词变名词："验证"，不写"进行验证"。
4. 用具体值代替模糊词："3 条来源"，不写"一些来源"。禁用：相关、等等、一些、适当、尽量、较大、显著（无数据时）。
5. 技术名称按产品原样写：按钮文字、字段名、命令、路径。
6. 名词串不超过 3 个。

## 2. 句

1. 一句一个主题。
2. 步骤句 ≤40 字。描述句 ≤50 字。
3. 主动语态，写出动作的主体。
4. 步骤用祈使句：点击、运行、检查。
5. 条件在前："如果 X，则 Y。"
6. 不用分号连接分句。冒号只用在列表或解释之前。
7. 括号只放引用、单位、短标识。

## 3. 段与节

1. 一段一个主题，≤6 句。首句是主题句。
2. 最重要的信息放最前。
3. 用连接词表示顺序与因果："因此""然后""如果"。
4. 复杂内容用列表或表格。表格必有表头。

## 4. 标题

1. 章节标题是论点句，≤25 字。
2. 不用"概述""介绍""背景"这类无信息标题。
3. 标题不重复正文首句。

## 5. 警告与注意

1. 警告（数据、资金、安全风险）与注意（系统风险）放在步骤之前。
2. 以命令开头，再给原因。
3. 格式：`> **警告**：…` / `> **注意**：…`。

## 6. 中文禁词表（页面文案）

营销腔：赋能、一站式、全方位、打造、助力、引领、革命性、颠覆、极致、无缝、解锁、拥抱、重塑、新范式。

套话结构："不是 X，而是 Y"；三联排比；冒号后揭晓；"值得注意的是"；每段以反问开头。

话术类（项目叠加层生效时）：建议你问、可以说、切入点、打动、痛点话术、引导对方。

## 7. 数字与单位

1. 数字与单位之间留不换行空格："5 080.8 亿元"或"5080.8 亿元"，全文统一。
2. 百分比写 "-5.4%"，正负号写全。
3. 日期写 YYYY-MM-DD。
4. 中英之间留一个空格。

## 8. 自检

1. 有超长句吗？拆。
2. 每段一个主题、≤6 句吗？
3. 术语都在术语表里吗？
4. 步骤是编号、祈使、一步一动作、条件在前吗？
5. 模糊词都换成具体值了吗？
