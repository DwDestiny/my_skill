# 叙事结构与讲解逻辑

## 1. 先分类：这一页主要是哪一类

借 Diátaxis 的四分法，一页以一类为主，不混写。

| 类 | 读者在做什么 | 结构 |
|---|---|---|
| 解释 | 想弄懂为什么、是什么 | 概念递进 + 答案先行 |
| 参考 | 要查一个事实 | 表格、术语表、按对象分组 |
| 教程 | 跟着学会一件事 | 步骤、每步一个结果 |
| 操作指南 | 要完成一个任务 | 条件在前的步骤 |

行业讲解页通常是"解释"加少量"参考"。

## 2. 叙事模式

| 模式 | 适用 | 用法 |
|---|---|---|
| 地图式总分总 | 内容多、读者会跳读 | 默认。开头一张全貌（摘要或总览图），中间分区，结尾回扣结果 |
| 答案先行（金字塔） | 判断型章节 | 首句写结论，证据在下，分组理由同层同角色 |
| SCR（情境—复杂—问题） | 读者要先接受背景 | 导语 2 到 3 句，不超过一段 |
| 问题—方案 | 说明某项成果解决什么 | 只写"解决什么、证据是什么、边界在哪"，不写推进 |
| 概念递进 | 概念有前置依赖 | 先基础后派生；每章新概念 ≤3 |
| 时间线 | 演进、里程碑 | 按真实时间间距；节点 ≤8 |

一个页面可混用：总体地图式，判断章答案先行，概念区递进。组数按内容定，不强制三条。

## 3. 取舍规则

| 去向 | 判据 | 位置 |
|---|---|---|
| 主线 | 直接支撑某条结果；没有它读者无法理解后文 | 章节正文 |
| 折叠 | 支撑证据、数据明细、方法说明、边界案例、反面证据 | 章节内折叠块 |
| 附录 | 全量来源表、术语表、原始数据、口径差异清单 | 页尾 |
| 删除 | 不挂任何结果；重复已有信息；so-what 测试答不出 | 不进页面，记入删除清单 |

so-what 测试：删掉这句，读者的哪条结果受损？答不出就删。

信息缺口单独成节，放在结论之后、附录之前。

## 4. 讲解逻辑

1. 陌生概念四步：类比（读者已知的事物）→ 定义（一句话）→ 例子（资料里的真实情形）→ 边界（它不是什么）。
2. 每屏一个主题。一章引入新概念 ≤3 个。
3. 术语首次出现即解释，之后全文同一个词。类比词不进术语。
4. 抽象陈述后 1 屏内给例子。
5. 章末检查点："读完这节你能……"，对应一条结果。可附一道自测题，不用弹窗。
6. 速读通道：只读顶部摘要与每节首句，也能得到完整主线。

## 5. 认知负荷检查

| 项 | 上限 |
|---|---|
| 章节长度 | 1 到 3 屏 |
| 一章新概念 | 3 |
| 一屏主题 | 1 |
| 折叠层数 | 2（主线 + 折叠） |
| 顶部摘要要点 | 3 到 5 |
| 标题 | 25 字 |
| 一段 | 6 句 |
| 同屏可见的图 | 2 |

## 6. 外行测试

有条件时让一位非行业读者读摘要与第一章，圈出看不懂的词。把圈出的词回写术语表，补类比或例子。没有条件时，由另一个不看资料的代理读蓝图并复述三条要点。
