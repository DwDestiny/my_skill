# 叙事结构与讲解逻辑

## 1. 先分类：这一页主要是哪一类

借 Diátaxis 的四分法，一页以一类为主，不混写。

| 类 | 读者在做什么 | 结构 |
|---|---|---|
| 解释 | 想弄懂为什么、是什么 | 概念递进 + 答案先行 |
| 参考 | 要查一个事实 | 表格、术语表、按对象分组 |
| 教程 | 跟着学会一件事 | 步骤、每步一个结果 |
| 操作指南 | 要完成一个任务 | 条件在前的步骤 |

行业讲解页通常是"解释"加少量"参考"。

## 2. 叙事模式

| 模式 | 适用 | 用法 |
|---|---|---|
| 地图式总分总 | 内容多、读者会跳读 | 默认。开头一张全貌（摘要或总览图），中间分区，结尾回扣结果 |
| 答案先行（金字塔） | 判断型章节 | 首句写结论，证据在下，分组理由同层同角色 |
| SCR（情境—复杂—问题） | 读者要先接受背景 | 导语 2 到 3 句，不超过一段 |
| 问题—方案 | 说明某项成果解决什么 | 只写"解决什么、证据是什么、边界在哪"，不写推进 |
| 概念递进 | 概念有前置依赖 | 先基础后派生；每章新概念 ≤3 |
| 时间线 | 演进、里程碑 | 按真实时间间距；节点 ≤8 |

一个页面可混用：总体地图式，判断章答案先行，概念区递进。组数按内容定，不强制三条。

## 3. 取舍规则

| 去向 | 判据 | 位置 |
|---|---|---|
| 主线 | 直接支撑某条结果；没有它读者无法理解后文 | 章节正文 |
| 折叠 | 支撑证据、数据明细、方法说明、边界案例、反面证据 | 章节内折叠块 |
| 附录 | 全量来源表、术语表、原始数据、口径差异清单 | 页尾 |
| 删除 | 不挂任何结果；重复已有信息；so-what 测试答不出 | 不进页面，记入删除清单 |

so-what 测试：删掉这句，读者的哪条结果受损？答不出就删。

信息缺口单独成节，放在结论之后、附录之前。

## 4. 讲解逻辑

1. 陌生概念四步：类比（读者已知的事物）→ 定义（一句话）→ 例子（资料里的真实情形）→ 边界（它不是什么）。
2. 每屏一个主题。一章引入新概念 ≤3 个。
3. 术语首次出现即解释，之后全文同一个词。类比词不进术语。
4. 抽象陈述后 1 屏内给例子。
5. 章末检查点："读完这节你能……"，对应一条结果。可附一道自测题，不用弹窗。
6. 速读通道：只读顶部摘要与每节首句，也能得到完整主线。

### 4.1 讲课页（投屏授课）

讲课页是讲者投屏、学员边听边看的页面。屏上只放学员此刻要看的东西，讲者要讲的话放讲者条。

1. 按费曼学习法排每个概念：案例里的一刻（学员先看到现象）→ 一句白话（给它起名字）→ 回到案例检验（这一刻为什么算这个概念）→ 学员讲回一遍（用一句话讲给同桌）。
2. 先定课程在整套课里的位置。第一次见到方法的课：概念在案例里第一次出现时才引入。衔接课（学员已听过方法，这节要接到实操）：先用一段方法论回顾把整张地图摊开，再让案例沿地图一格一格走，最后回看地图并练习。
3. 一页一个要点。屏上：一句主句（≤20 字）+ 一张图或一组卡片／表，最多 3 个短标签（每个 ≤12 字）。画面要填满：图占一半以上，正文块在屏上垂直居中，投屏字号让最后一排能读。
4. 给长课加串联：每段开头一页说这一段问什么、交出什么、常见偏差；每段结尾在同一张总表上填一行；每页右上角标当前位置。学员任何时候都知道自己在地图哪一格。
5. 图的主体用案例里的真实物件和原话：单据、工单、时间线、客户的一句话。
6. 讲者要点、出处、参考答案不上屏，放讲者条或讲者手册。
7. 交给用户看的是画出来的试样页，不是逐页文字表。蓝图是内部底稿，用户不需要读它。

| 平庸 | 好 |
|---|---|
| 一页列出“业务事实 / AI 辅助 / 规则和人”三栏，每栏四五行说明 | 一张费用单据画在中间，三个箭头分别指向“AI 读出数字”“规则算出偏高”“人判断是否违规”，主句：“AI 给线索，人下结论” |
| 衔接课 10 页试样：直接从案例第一刻开始，页与页之间没有“现在在哪一步”，每页下半屏空着 | 约 80 页三部分：方法论回顾（各步、各条线、关键概念、一张空总表）→ 案例沿各步走（每步开头页 + 总表行）→ 回看与练习；右上角标“二 · 第 3 步” |
| 先用两页讲概念定义，三节后才出现客户原话 | 先放客户的一句原话，再给名字：“这就是紧迫性” |

## 5. 认知负荷检查

| 项 | 上限 |
|---|---|
| 章节长度 | 1 到 3 屏 |
| 一章新概念 | 3 |
| 一屏主题 | 1 |
| 折叠层数 | 2（主线 + 折叠） |
| 顶部摘要要点 | 3 到 5 |
| 标题 | 25 字 |
| 一段 | 6 句 |
| 同屏可见的图 | 2 |

## 6. 外行测试

有条件时让一位非行业读者读摘要与第一章，圈出看不懂的词。把圈出的词回写术语表，补类比或例子。没有条件时，由另一个不看资料的代理读蓝图并复述三条要点。


## 7. 踩坑记录

- 做了什么：把 4 节 62 页的蓝图（每页一行：屏上内容、讲者要点、依据）渲染成网页，发预览链接请用户看。
- 用户原话：“字太多太密了，没法用，你想清楚场景，讲课，还是一样，用图文并茂的方式，参考费曼学习法，把案例融入进去”。
- 原因：没有从使用场景出发。讲课时学员看的是投屏，讲者需要的是一页一图；我交的是逐页文字表，屏上内容一格写了五六句。另外，方法和案例分节讲，案例像附加材料。
- 改法：见第 4.1 节。用户要看的是画出来的试样页；屏上文字按 4.1 第 3 条的上限写；概念按费曼顺序从案例里引出。
