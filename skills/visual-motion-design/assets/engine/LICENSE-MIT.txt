motion-engine.js 与 engine.css 的许可说明

本目录的引擎派生自 juliobsz/skills 仓库中 awwwards skill 的 motion engine
（references/engine.md 与 tests/*/src/engine/*）。保留的部分：数据属性 API 的命名
（data-reveal、data-split、data-intro、data-delay、data-parallax、data-magnetic）、
head 内联标志脚本（html.js 与 html.motion）、加载器"跟随真实进度、1.1 秒下限、2.6 秒上限"
的规则、减少动效时内容全部可见的门控方式、"一个时钟"的原则、缓动词汇表的四个名字。
重写的部分：原实现依赖 GSAP、ScrollTrigger、SplitText 与 Lenis；本文件改用 Web Animations API、
IntersectionObserver 与一个 requestAnimationFrame 时钟，零依赖，可离线打开。
