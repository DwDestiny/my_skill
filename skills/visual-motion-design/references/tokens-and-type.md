# 令牌、排版与色彩

起点文件：`assets/base-tokens.css`。名字是契约，值按设计计划改写。

## 1. 令牌三层结构

| 层 | 作用 | 例子 |
|---|---|---|
| 原始值 | 灰阶、透明度阶 | 灰 0 到 900；同一墨色的 5%、10%、20% 透明度 |
| 语义 | 按角色命名 | `--bg` `--surface-1` `--ink` `--ink-2` `--line` `--accent` |
| 组件别名 | 指向语义 | `--card-bg: var(--surface-1)` |

深浅色只重载语义层。组件不在媒体查询里写颜色。来源：open-claude-ui 的令牌分层方法（只取方法，不取色值）。

## 2. 表面、边框、阴影

1. 面板比底色高一档明度（2 到 6 个明度点），不用描边分层。
2. 边框用同一墨色的低透明度（约 10% 到 16%），换底色时自动适配。
3. 单闭合边框原则：从画布向内的视线最多穿过 1 层闭合边框。容器里的子控件改用填充或幽灵样式。
4. 阴影只给浮层（弹层、拖拽中的卡片）。静止元素无阴影。阴影分两层：近处小而浅，远处大而淡。
5. 深色模式不画外框，用内侧 1px 低透明度白色高光。
6. 高分屏发丝线可用 0.5px。

## 3. 中文排版

| 项 | 值 | 说明 |
|---|---|---|
| 正文字号 | 16 到 18px | 17px 为默认 |
| 正文行高 | 1.7 到 1.9 | 英文规则的 1.45 到 1.6 对汉字太挤 |
| 每行字数 | 32 到 40 字 | 版心约 600 到 720px |
| 最小字号 | 12px | 图内、来源、图注都不低于 12px |
| 显示字行高 | ≥1.1 | 不用英文显示字的 0.85 到 1.0 |
| 字距 | 0 | 汉字不加负字距；拉丁显示字可 −0.02 到 −0.04em |
| 标点 | 全角 | 行首不出现句号、逗号、顿号（浏览器默认处理，长标题手动断行时检查） |
| 数字 | `font-variant-numeric: tabular-nums` | 表格、计数、时间列右对齐 |
| 单位 | 数字与单位间不换行 | 用 `&nbsp;` 或 `white-space: nowrap` |
| 标题 | `text-wrap: balance`，≤2 行 | 中文标题 ≤25 字 |
| 正文 | `text-wrap: pretty` | |
| 长串 | `overflow-wrap: anywhere` | URL、代码、文件名 |
| 中英混排 | 中英之间留一个空格 | 例："RAG 检索" |

标题行数估算：每行可容纳字数 ≈ 行宽 ÷ 字号（汉字 k=1.0）。

## 4. 字阶

角色绑定字号、行高、字重。不在组件里临场发明字号。

| 角色 | 建议 | 预算预设 |
|---|---|---|
| display | clamp(2.5rem, 1.6rem + 3.2vw, 4.5rem) 起，show 档可更大 | mixed / show 舞台区 |
| h1 | 1.75 到 2.5rem | 全部 |
| h2 | 1.25 到 1.5rem | 全部 |
| body | 1.0625rem | 全部 |
| small | 0.875rem | 全部 |

同屏字号 ≤4（用户规则）。全页角色数 ≤5（clear）或 ≤6（mixed / show）。标题与正文比 ≥1.6，display 与正文比 ≥2.5。

## 5. 字体栈

默认：联网字体在前，系统中文字体栈在后。片段见 `assets/fonts-web.html`，接线见 `base-tokens.css`。

| 角色 | 默认 | 说明 |
|---|---|---|
| 正文 | Noto Sans SC（400 到 700） | Google Fonts 按字切片，只下载页面用到的字 |
| 显示 | Bricolage Grotesque（600、700） | 只含拉丁与数字，汉字落到 Noto Sans SC 粗体 |
| 回退 | `--font-system` | PingFang SC、Microsoft YaHei、Noto Sans CJK SC 等 |

联网字体规则：

> **注意**：字体被拦截或离线时，页面仍须完整。`font-display: swap` 与完整回退栈不能省。

1. 不必先问用户。字体样式只从 Google Fonts 加载。
2. 需要更稳时，改为自托管 woff2（≤4 个文件，预加载 ≤2 个）。
3. `font-display: swap`，并写完整回退栈。
3. 不把 Inter、Space Grotesk 当"安全默认"。不引用任何厂商专有字体名。
4. 1 到 2 个字族。第 2 个字族必须明显不同并有职责（例如显示字与正文）。

## 6. 色彩

1. 一个底、一个墨、一个强调色。强调色占任一屏 <5%，只用于动作、焦点和至多一处焦点元素。
2. 状态色（good / warn / bad）固定，不随主题翻转，必须配文字或形状。
3. 可信度标记（事实 / 判断 / 缺口；高 / 中 / 低 / 未验证）用形状加文字区分，不只靠颜色。
4. 中性灰带一点强调色的色相，不用纯中灰。
5. 深色模式是独立挑选的一套值，不是反色。深色下正文不加粗，亮度略降。
6. 禁止：奶油底加陶土强调加衬线标题（接近 #F4F1EA 配 #D97757）、近黑底加单一酸绿或朱红、紫蓝渐变。
7. 舞台区色场（mixed / show）是概念材料，仍要保证叠加文字 4.5:1，并由 `<html>` 上一个全局变量驱动全部文字色。

对比度计算（离线，不需要联网）：加载 `dataviz` skill 后，用其 `scripts/validate_palette.js` 导出的 `contrast(a, b)`，或按 WCAG 相对亮度公式手算。浅色与深色两套都算。

## 7. 间距

一套刻度：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128px。全部 margin、padding、gap 只取刻度值。节间距明显大于节内间距（桌面 72 到 160px，手机 48 到 96px）。用 flex / grid 的 `gap`，不用逐元素 margin。

## 8. 圆角

按角色分阶：控件 6px、卡片 10px、弹层 16px、胶囊 999px。嵌套时外圆角 = 内圆角 + 内边距。不同角色的卡片不得同一圆角。
