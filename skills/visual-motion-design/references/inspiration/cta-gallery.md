# cta.gallery：行动号召案例库与写作提示

核实：2026-10-15 读首页、`/cta-tips`、`/cta/tines`。未看截图。许可与价格：未写。有赞助与广告位。无源码。

## 1. 结构与网址

| 项 | 内容 |
|---|---|
| 类型页 | `/categories/button`、`call-to-buy`、`download`、`form`、`modal-pop-up`、`navigation`、`newsletter`、`pricing` |
| 其他 | `/cta-tips` 写作提示，`/templates` 模板（赞助），`/submit`、`/about`、`/subscribe` |
| 条目页 | `/cta/<名称>` |
| 条目页字段 | 标题、简介、发布日期、行动号召的文字、类型、行业、模式（亮或暗）、桌面与手机截图、相关条目 |
| 示例条目 | Kronborg、Tines、Numa、Animos、Trevornoah、Studioloop、Augustus、Jemini、Greenboard、Native Security 等 |

## 2. 写作提示（`/cta-tips`，15 条，转述）与本项目的取舍

| 序 | 提示要点 | 讲解页 |
|---|---|---|
| 1 | 清楚直接，说明会发生什么 | 采用 |
| 2 | 以动词开头 | 采用。例："查看来源" |
| 3 | 写出好处 | 采用，改为"写出结果"。例："展开 3 条来源" |
| 4 | 用第一人称（"开始我的试用"） | 不采用。按钮写结果，不写"我的" |
| 5 | 诚实的紧迫感 | 不采用。讲解页没有时限 |
| 6 | 短 | 采用。1 到 4 个字（`components.md` 第 12 节） |
| 7 | 对比度够 | 采用。正文 4.5:1，大字 3:1 |
| 8 | 关键行动放首屏 | 部分采用。主操作放首屏顶部摘要内 |
| 9 | 降低风险感 | 不适用 |
| 10 | 回应顾虑 | 不适用 |
| 11 | 社会证明 | 不采用。可信度标记取代它，且不靠人数 |
| 12 | 立即价值 | 采用。折叠头写清里面是什么（`components.md` 第 3 节） |
| 13 | 测试迭代 | 不适用。无流量 |
| 14 | 标题配合 | 采用。按钮前一句要说明对象 |
| 15 | 避免泛词（"点击这里"） | 采用 |

结论：提示 1、2、3、6、7、12、14、15 可用。其余是转化优化，讲解页不用。

## 3. 怎么用

1. 讲解页的"行动"只有：展开、查看来源、回到页首、复制、打开术语。不是销售转化。
2. 查 `/categories/button` 和 `/categories/navigation` 看按钮状态与位置。`pricing`、`newsletter`、`call-to-buy` 不看。
3. 只对 预设 `show`或纯展示页看 `modal-pop-up`。

## 4. 示例：来源按钮

| 项 | 内容 |
|---|---|
| 任务 | 每条断言后有来源入口，点击弹出来源行（`components.md` 第 5 节） |
| 文案 | "来源 C006"。不写"了解更多""点击查看" |
| 状态 | hover、pressed、focus-visible、disabled 四态齐全 |
| 取 | 提示 2、6、15 |
| 舍 | 提示 4、5、11 |
| 记录示例 | `cta.gallery / cta-tips / 取：动词开头、短、不用泛词 / 舍：第一人称、紧迫感 / 理由：讲解页不做转化` |

## 5. 不适用

1. 任何带"免费试用""限时""加入 N 万人"的写法：与可信度规则冲突。
2. 弹窗订阅：不收集联系方式。
