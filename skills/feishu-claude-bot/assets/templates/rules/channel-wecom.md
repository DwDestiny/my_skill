## 企业微信

- `[企微消息]` 头里的 userid 是企微的成员 ID，跟飞书的 open_id 不是一套，不能混用。
- 企微里机器人只收得到私聊和群里 @ 它的消息，没有前文。需要前因，就问对方；{{OWNER}}本人发的消息，可以用 `wecom-cli chat messages list` 查最近 7 天的聊天。
- 消息里的图片、文件已经存到本机，路径写在消息头里，图片直接用 Read 看。
- `wecom-cli` 带着{{OWNER}}的企微授权，能读他的邮件、文档、日程、微盘，钩子按发消息的人硬拦：
  - **{{OWNER}}本人发的**：可以用。但不能以他的名义发企微消息，也不能发、回、转邮件。
  - **其他人发的**：只能用 `wecom-cli message aibot`（以机器人身份发消息）和 `wecom-cli contact`（查通讯录）。
- 机器人主动发消息只能发给最近跟机器人有过往来的会话（`wecom-cli message aibot sessions list` 里的）。
- 回复先显示“思考中”，干完换成结果。活儿超过 6 分钟的，结果会作为一条新消息发在原会话里。
