# 手法目录与技术栈地图

> 何时读：阶段 3 选组件时。
> 读完做什么：先看"读者感觉到什么"，选出手法。再看"代价"和第 3 节，确认技术能承担。
> 本文件是知识，不是门禁。表里的"适用""不适用"是起点判断，不是通过线。
> 来源：2026-10-19 作品集调研，私有底稿，未入库。17 个站，每个站有观察卡，部分截图由调研者亲自核对。
> 范围：
> 1. 3D 展厅类没有样本。Lusion、Resn、Bruno Simon、cassie.codes、samsy.ninja、zajno 都渲染失败或卡死。本文不涉及滚动驱动相机穿行、粒子世界。
> 2. 技术栈与品味几乎不相关。同样优雅的站，从零框架手写（Lynn）到 three.js（Robin）都有。选手法先看"读者感觉到什么"，再看技术。
> 3. 悬停、转场、滚动的时序，除 elaya 外没有实测。
> 标记：站名后写"亲核"表示调研者看过该站截图。没写的来自采集 agent 的观察卡。"性价比"是推断，不是测量。每表内的行按效果除以代价从高到低排。

## 1. 手法目录

性价比最高的几乎都是决定，不是技术：灰阶统一、一处签名、强调色只标一个状态、刻度尺位置指示。最贵的是滚动接管与 WebGL。它们只在作品本身配得上时才值得。[推断]

## 2. 技术栈地图

技术栈只决定"能做哪类手法"和"要付什么代价"。最大的风险是滚动接管与 canvas 文字，它们直接伤害无障碍。

证据等级：

| 等级 | 含义 |
|---|---|
| [实测] | 在浏览器里读到全局变量、计算样式或源码配置 |
| [文件路径] | 在 HTML 里看到脚本或资源的具体路径 |
| [HTML 关键词，未确认] | 采集 agent 只在 HTML 里数到关键词次数。可能是别的单词的一部分，或旧资源。不能当结论 |

| 想要的效果 | 常见实现 | 本批证据与等级 | 代价与风险 | 无 GPU 的 VPS 能否验证 |
|---|---|---|---|---|
| 可视化搭建出精致页 | Framer | elaya：入场动效配置在源码里，并读取 Reduce Motion [实测] | 默认组件易同质。第三方嵌入留默认文案（elaya 的 cal.com 预留语） | 能。静帧与悬停时序都采样过 |
| 可视化搭建 | Webflow | Cuberto 出现 3 次 [HTML 关键词，未确认] | 同上 | 能 |
| React 应用框架 | Next.js | Rauno、Emil、Benji、Josh、Linear、Raycast、Darkroom、Robin（Next 9 一代）[文件路径] | 框架不决定品味。同为 Next，有 Emil 也有 Raycast | 能 |
| 内容型静态框架 | Astro | Olivier（`/_astro/` 路径）[文件路径]。Cuberto 出现 870 次 [HTML 关键词，未确认] | 无特别风险 | 能 |
| 手写静态站 | 无框架 | Lynn（只有一个 main 脚本加统计）、Aristide（约 4 KB HTML 加自写脚本）、Pentagram（类 Vite 构建产物）[文件路径] | 靠个人维护 | 能 |
| 平滑滚动 | Lenis | Olivier（lenis 类名）[HTML 类名]。Darkroom 出现 11 次，团队是作者 [HTML 关键词，未确认] | 接管滚动，程序化滚动失效 | 部分。要用滚轮事件驱动 |
| 平滑滚动 | Locomotive Scroll | Dennis（脚本与样式文件）[文件路径] | 同上。版本偏旧 | 部分 |
| 滚动驱动动画 | GSAP 加 ScrollTrigger | Dennis（cdnjs 链接，全局 gsap 存在）[实测] | pin 过长，体积 | 部分 |
| 滚动驱动动画 | 原生 scroll-timeline | 本批无证据 | 未知 | 能做静态检查 |
| 横向滚动 | 自写 | Rauno（无库全局变量）、Aristide（自写逐帧循环）[实测] | 键盘与读屏 | 部分 |
| 组件动效 | Motion（原 Framer Motion） | Emil（Motion 全局标记）[实测] | 打包体积 | 能。时序可采样 |
| 矢量动画资产 | Rive、Lottie | Dennis 与 Obys 的 "rive" 字样 [HTML 关键词，未确认，不能当证据] | 未知 | 未知 |
| 页面转场 | Barba.js | Dennis（脚本地址与 namespace 属性）[文件路径] | 焦点管理、状态保持 | 部分 |
| 页面转场 | View Transitions API | Olivier 0 命中。本批无证据 | 未知 | 能 |
| 3D 与着色器 | three.js | Robin（脚本包内约 525 次，1 个 canvas）[包内关键词，较可靠]。Darkroom 4 次、Linear 1 次 [HTML 关键词，未确认] | 重。低端机发热。Reduce Motion 处理未验证 | 否。软件渲染慢或卡死 |
| 3D | 自研 WebGL，引擎未知 | LHBZR（全屏 canvas，有 WebGL 检测）[实测]。Aristide 脚本 2 次、Obys 疑似 canvas [HTML 关键词，未确认] | canvas 内文字不进 DOM | 否 |
| 3D | R3F、OGL、Spline | 本批无证据 | 未知 | 否 |
| 3D 展厅 | 不明 | Lusion、Resn、Bruno Simon、cassie.codes、samsy.ninja、zajno 全部渲染失败 | 本文空白 | 否 |
| 个性字体 | 自托管 woff2 | Olivier 预加载 4 个字体文件 [文件路径]。Lynn、Robin、Dennis 的专用字体名 [实测，计算样式] | 授权，加载闪烁 | 能 |
| 通用无衬线 | next/font 托管 Inter 类 | Benji、Linear [实测]。Raycast 类 Inter [截图判断，未确认]。elaya 用 Space Grotesk [实测] | 同质，"像所有人" | 能 |
| 预渲染 3D 角色 | 3D 软件出静图 | Josh 小人 [截图判断，未确认格式] | 要做角色资产 | 能 |
| 声音 | 音频元素或 Web Audio | Josh 开关、Darkroom 按钮、LHBZR 署名 [实现均未确认] | 浏览器自动播放限制 | 部分 |
| 无障碍与 Reduce Motion | prefers-reduced-motion 媒体查询 | elaya 读取 [实测，源码]。Dennis 未见 [观察]。其余未测 | 接管滚动与 canvas 文字最伤 | 能。可模拟该媒体查询 |

> **注意**：Rauno 与 Dennis 的观察卡都写到程序化滚动失效、只能用滚轮驱动。这是无障碍风险的直接证据。采用滚动库前，先写键盘与读屏的退路。
