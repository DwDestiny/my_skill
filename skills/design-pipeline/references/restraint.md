# 收放原则

炫技是默认，浮夸是错误。本文件说明效果放在哪里、放多大、什么时候算浮夸。来自：旧 `references/flash-rules.md` 第 1、2、4、5 节，改为按动效气质判断。

用户原话："既然做了UI…那肯定是要炫技，只是…是否过于浮夸等等要考虑"。

## 1. 三句话原则加一条

1. 正文可读：正文对比 ≥4.5:1，动效层不压正文。
2. 动效回答一个动作或一个状态变化。
3. 首屏 3 秒内有可读标题。
4. 签名时刻全页只有 1 处。其余效果为它让路。

## 2. 四条禁区

| 编号 | 禁区 | 判定 |
|---|---|---|
| 禁 1 | 没有概念承载 | 手法不能用一句话说出它表达主题的哪一点 |
| 禁 2 | 挡住阅读 | 动效层、3D、视频与正文区重叠，或正文对比低于 4.5:1 |
| 禁 3 | 同一手法重复超过 2 次 | 同一表现形式 id 在 `design.md` 第 2 节出现 3 次以上 |
| 禁 4 | 出现在阅读区 | 阅读区只允许反馈与状态动效 |

## 3. 动效气质

气质在阶段 2 定，写进 `design.md` 第 1.3 节。气质是氛围决定，也是案例 `atmosphere_fit` 的提示值。气质不过滤发牌。

| 气质 | 什么在动 | 何时动 | 占屏 |
|---|---|---|---|
| 静 | 只有反馈动效（悬停、按下、焦点、展开） | 用户动作后，≤200 ms | 元素自身 |
| 呼吸 | 静 加 1 处环境动效（液面、颗粒、光斑） | 持续，周期 ≥4 s，不随滚动变 | ≤10% 视口 |
| 驱动 | 滚动或指针驱动的舞台（相机、进度、揭示），入场每章 1 种 | 随滚动或指针 | 舞台 ≤60% 视口，阅读区不动 |
| 沉浸 | 全视口舞台，滚动驱动相机或场景状态，允许 pin 段 | 随滚动 | 全视口，签名时刻在此 |

四种气质都有 Reduce Motion 退路，退路等于静。退路只去运动，不去状态：步骤跟随滚动位置是状态变化，Reduce Motion 下仍要切换。

## 4. 浮夸判定表

每页逐行看。列出的是所选气质的建议范围。任一行落到"过量"，就按第 5 节收。

| 维度 | 静 | 呼吸 | 驱动 | 沉浸 | 过量 |
|---|---|---|---|---|---|
| 动效占屏比例 | 元素自身 | ≤10% | ≤60%，阅读区 0 | 全视口，仅舞台段 | 阅读段动效 >10%，或舞台盖住正文 |
| 同屏同时运动的元素数 | ≤2 | ≤3 | ≤4 | ≤8 | >8 |
| 首屏可读内容（标题、一句说明、主操作） | 全部 | 全部 | 全部 | 标题与主操作 | 任一项不可读 |
| 首屏出现内容的时间（4G、中端手机） | ≤1.5 s | ≤2.5 s | ≤2.5 s | ≤3 s | >3 s |
| 对正文的遮挡 | 0 | 0 | 0 | 仅背景层，正文对比 ≥4.5:1 | 遮挡正文或对比不足 |
| 无限循环动效数 | 0 | 1，可暂停 | ≤1，可暂停 | ≤2，可暂停 | >2，或不可暂停 |
| pin 总屏高（ScrollTrigger pin 与停留超过 1 屏的 sticky 舞台） | 0 | 0 | ≤2 屏高 | ≤5 屏高 | >5 屏高，或到不了页脚 |
| 闪烁 | 无 | 无 | 无 | 无 | 1 秒内超过 3 次闪光 |
| Reduce Motion 退路 | 有 | 有 | 有 | 有 | 无 |

阈值依据：4.5:1 来自 WCAG 1.4.3。可暂停来自 WCAG 2.2.2。3 次闪光来自 WCAG 2.3.1（未核原文）。其余数值是建议值。

已有裁定（E1 样例，2026-10-16）：

- 相机穿行形态只数停靠与 pin，不把整条相机轨道算 pin。
- 承载可信度的来源行算正文。被材质层盖住就是遮挡，改位置，不删层。
- 一次性入场在 2.5 s 内按一组计。持续运动按个数计。

怎么看：先看截图与录屏。可选用 `python3 -I toolbox/flash-check.py <index.html>` 扫循环、pin 与 Reduce Motion 分支，用 `toolbox/shots.py` 截图。

## 5. 收的顺序

1. 先改位置：把手法移出阅读区，移到舞台区。
2. 再改幅度：降低位移，缩小面积，减少同屏元素。
3. 再改频率：循环改为一次性，或加暂停控件。
4. 仍过量才删除。删除写进报告，写删了什么、为什么。

## 6. 降级不是收放

用户原话："动效引擎和视觉炫技不应该降级"。

收放是把效果放对位置、给对幅度。降级是因为怕浮夸就关掉 3D、换掉流体、把舞台改成静态图。降级不解决浮夸，只把页面推回平庸。遇到过量，按第 5 节先改位置、幅度、频率。不要先换成更弱的技术。选静气质是氛围决定，不是降级：静气质的页面仍要有材质、光、空间和签名时刻。
