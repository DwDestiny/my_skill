# 迭代循环：保留最好的一版，只让更好的版本替换它

> 何时读：阶段 2 选方向（方向循环）和实现后看图（整页循环）时。
> 本文件管"怎么迭代、什么时候停"。"怎么判断好坏"见 `judging.md`。
> 来源：团队页第五次实测（2026-10-20，下称"r5"）。首批 A（满屏现场照）是全程最接近能用的一版，被退回后换成三联肖像，再铺成整页，中段变成表单和文件阅读器，越改越差。过程中没有任何一步要求新版本证明自己比旧版本好。

## 1. 冠军与挑战者

1. **冠军**：到目前为止最好的一版。第一版做出来就是冠军。冠军的截图和源文件留档，不覆盖。
2. **挑战者**：每一轮的新版本。
3. 挑战者只有在盲比中赢过冠军，才成为新冠军（`judging.md` 第 4 节）。输了就丢弃挑战者，回到冠军继续，不在挑战者上叠改动。
4. 用户说某一版好，那一版直接成为冠军，评审结论让位。

原因：没有冠军时，"新"会被误当成"好"。r5 每一轮都换了东西，没有一轮被要求证明比上一轮更让人停住。

## 2. 每一轮做什么

| 步 | 做什么 | 产出 |
|---|---|---|
| 1 | 截图：1440 首屏、最平的一屏（整页循环才有）、390 首屏 | 3 张以内的图 |
| 2 | 独立评审盲评：挑战者对冠军、挑战者对 2 到 3 个高分锚点（`judging.md` 第 3、4 节） | 胜负、档位、证据 |
| 3 | 判定：赢了换冠军，输了退回冠军 | 冠军是谁 |
| 4 | 只选一个最该改的地方：先看第一眼停留力，再看氛围，再看其余（`judging.md` 第 5 节决定深化还是换方向） | 下一轮的一句改法 |
| 5 | 在 `design.md` 第 1.6 节迭代表记一行 | 一行记录 |

一轮只改一件大事。同时改五处，赢了不知道是哪一处起的作用，输了也不知道该退哪一处。

## 3. 什么时候停

满足任一条就停：

| 条件 | 怎么停 |
|---|---|
| **达标**：冠军的第一眼停留力达到 4 档、其余维度不低于 3 档（`judging.md` 第 2 节），且是在和高分锚点并排时评出的 | 交给用户看。写"可以给用户看"，不写"审美通过" |
| **平台期**：连续 2 轮挑战者都没赢过冠军 | 交出冠军，写卡在哪个维度、试过哪两种改法 |
| **轮数上限**：方向循环 3 轮，整页循环 3 轮，全程合计不超过 6 轮 | 交出冠军，写未达标的维度 |
| **同一个方向问题第二次被评为最差** | 停下来问用户。给冠军截图、问题和 2 个可选做法，不再自己循环。用户不在线（无人值守、headless 跑）时，把这三样写进 `process/ASK.md`，交出当前冠军并停止，不替用户选 |

原因：

- 没有上限时，模型会一直改下去，改动的重心会滑向容易验证的事（裁切、退路、标注、功能），第一眼的吸引力没人再管（r5 的实际走向）。
- 连续两轮赢不了说明当前做法到顶了，再改只是换花样。
- 同一个方向问题出现两次，说明这是取舍问题，取舍属于用户。

## 4. 两种循环

### 4.1 方向循环（阶段 2）

1. 用方向板（`stages/2-atmosphere.md` 2.2.1）做 2 到 3 个方向，盲评选出第一个冠军。
2. 之后每一轮二选一：
   - **深化**：在冠军的世界里改执行，例如减轻蒙版、换显示字、换裁切、加一层光。
   - **换方向**：只有冠军的第一眼停留力在 2 档以下时才换。
   - 判断规则见 `judging.md` 第 5 节。
3. 停下以后，冠军就是选定的方向。

### 4.2 整页循环（阶段 4 实现后）

1. 第一版整页做完就是冠军。
2. 每轮只改评审排第一的问题。方向问题仍排第一（`critique-method.md` 第 2 节）。
3. 技术检查（溢出、对比度、Reduce Motion、无 JS、断点、上下文丢失）只跑一遍，修完就关，不进这个循环，也不算轮数。原因：技术项能被确定地验证，混进循环会挤掉吸引力的轮次。

## 5. 不要这样做

| 做法 | 为什么不行 |
|---|---|
| 创作者给自己的版本打分 | 自己评自己会偏高。评审必须是没看过设计说明的独立会话 |
| 只和上一版比 | 两版都平庸时，"更好"毫无意义。每轮都要和高分锚点比 |
| 输了的挑战者也保留改动，再在上面修 | 退化就是这样叠出来的 |
| 用"修了几个问题"代替"赢没赢" | 修复数量和吸引力无关 |
| 达到上限后继续"再改一点" | 上限就是上限。交出冠军，让用户决定 |
