# 阶段 1 内容蓝图

> 何时读：收到设计需求后第一件事。
> 读完做什么：写接单槽位表，定载体，请 `content-blueprint` skill 出蓝图。
> 产物：`00-接单.md`、`01-载体.md`、`01-内容规划/blueprint.md`，并在 `design.md` 第 0 节登记三个路径。

本阶段回答"页面说什么、给谁看、用什么载体"。不选颜色、字体、版式、动效。那是阶段 2 的事。

## 1. 接单槽位表

| 槽位 | 怎么填 |
|---|---|
| 用户原话 | 逐字抄本次消息。加早先的风格要求和说话日期。不改字，不删字 |
| 风格词 | 原话里的风格词按字面记（如"高级""炫一点"）。不翻译成分级，不读成"少做" |
| 第一眼 | 一行。读者看第一眼要觉得什么。用用户能说出的话 |
| 载体 | 找原话里的载体词。没有时写"桌面 Web 加 390 移动（默认）" |
| 点名手法 | 原话点名的表现形式（3D、流体、视频背景、色差）。逐个一行。没有写"无" |
| 交付形态 | 单页 HTML、多页原型或 Artifact。发布 Artifact 前先问用户 |
| 资料路径 | 路径、内容一句、可信度（事实、判断、方案） |
| 缺口 | 缺什么资料，谁能补。没有写"无" |
| 执行方补充 | 原话以外由执行方加的受众、目标、转化、表单、合作流程，每项写依据。没有写"无"。原因：团队页第一次，执行方加入了"潜在合作方、四步工作方式、生成合作简报"，原话的"炫酷团队展示"被悄悄换成了"讲清合作方式" |
| 素材盘点 | 内容自带什么？彩色图像、产品界面、作品、只有文字，四选多。原因：阶段 2 的"颜色归谁"要用它 |
| 读者凭什么信 | 作者或客户的名气，还是页面本身？默认写"页面本身"。原因：决定能否用"省略型"手法 |

> **注意**：原话优先于一切规则。原话和本插件冲突时，按原话做，并在 `design.md` 写明冲突点。

检查：原话逐字在文件里。"第一眼"一行非空。

## 2. 载体

1. 运行 `node toolbox/lib.mjs carriers <id>` 取本项目载体的对象（`lib.mjs carriers` 列 9 种）。再读 `references/carriers.md` 的"HTML 平替"一节。
2. 把档案写进 `01-载体.md`：壳尺寸、字体栈、最小字号、最小命中区、断点、安全区、hover 有无、Reduce Motion 退路。
3. 壳尺寸等于视口。小程序与 App 不画设备外框（用户 2026-10-16 决定）。
4. 目标载体不能做原生时，写平替：字体栈、组件外观、手势替代、用 `:active` 代替 hover。
5. 逐个检查点名手法在该载体上是否可行。写限制与退路。
6. 来源标"未找到"的字段留空，写"未找到来源"。不编数值。

## 3. 蓝图

读 `content-blueprint` skill 的 `SKILL.md`，按它的步骤 0 到 11 做。本插件只加以下六条。

1. 先写产品层：根本目标（客户的业务目标与读者的目标分开）、工作故事 3 到 7 条按失败代价排序、每页或每章一张职责卡（含"禁止出现"）。
2. 职责卡标"我们的建议"。不写成客户已确认。
3. 每章加 `stage: yes|no` 与 `image_needs`。`image_needs` 每项含 `purpose`、`subject`、`kind`（data、mechanism、atmosphere）、`size`。没有写 `[]`。
4. 舞台章默认不少于总章数的 1/4。偏离时在 `design.md` 写理由。适用：展示型。不适用：操作型原型、成功/确认状态、需要重复结构做比较的页、短内容阅读页。职责卡写"视觉重量 = 主角"的章必须是舞台章。
5. 自问一次：删掉产品层三张表，章节结构会变吗？不变，说明产品层是抄的。重写。
6. 写使用频率：读一次，还是每天用？原因：决定动效速度与氛围剂量。

单页且章数 ≤8 时，受众结果、证据索引、术语表写成 `blueprint.md` 的附录节。多页面产品才分文件。

蓝图 front matter 里的 `reader_mode`（读、读看、看）是读者主要怎么用这页的提示，写进 design.md 第 0 节"第一眼要觉得什么"的依据。它不是分级，不决定收放。收放由阶段 2 的氛围决定。

## 4. 不做

| 禁止 | 原因 |
|---|---|
| 编资料里没有的事实 | 缺的写"未知" |
| 写沟通话术、提问顺序、销售说法 | 项目边界，由业务负责人决定 |
| 为每个载体建完整组件库 | 载体只定尺寸与平替 |
| 把桌面 Web 写成 macOS 或 Windows 原生 | 载体档案按 HTML 平替写 |
