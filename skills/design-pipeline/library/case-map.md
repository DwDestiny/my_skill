# 设计案例地图（2026-10-21）

> 何时读：选方向的第一步，先读本文件（约 9 KB），不整读 anchors.json、themes.json、references.json。
> 用法：1. 先按蓝图写出题材自己的世界（地方、时辰、谁在场、光从哪来，每项标来源），再用它找下面的簇，不用视觉手法找。簇名是光的形状，不是时辰："黑里只亮一处"不要求题材发生在夜里，白天的车间里只亮一块屏也成立。2. 簇里挑 2 到 3 条，`node toolbox/lib.mjs anchors <id>` 读全文，用 agent-browser 打开看一次，截首屏到项目临时目录。3. 对每条写换题清单（第 2 节）。4. 过不雷同三问（第 3 节）。
> 来源：anchors.json 的 30 个高分锚点（现场看过或获奖截图）、references.json 里 5 个身份类参照、主题库里少数案例。条目的网址、首屏描述、平庸版本都在 `lib.mjs anchors <id>` 里，这里只写装置和换题。

## 1. 按世界分簇

每条：名称（页型，档）装置一句；**换题**一句。装置分三层：**帧**（停下来那一张长什么样）、**动**（入场、滚动时什么在变、视频或 WebGL 接管了什么）、**跟手**（指针、悬停、点按带动什么）。2026-10-21 之前的条目只写了帧；写着"动：未录"的条目，借之前先 `python3 toolbox/record-motion.py --anchor <id> --out <临时目录>` 录一遍再看。获奖站的好有一半在动和跟手里，只借帧做出来的是一张暗照片加几条线（FDE 首跑的教训）。

### 1.1 黑里只亮一处

适合：夜班、值守、现场、设备、"安静里有一点在工作"。光是局部的，大面积留暗，文字缩小。

- Immersive Garden（studio-home，4）全黑里只照亮几朵白花和一只蜻蜓，标志被植物穿过。**换题**：你的题材里夜里还亮着的是什么（一块屏、一扇窗、一盏灯）就只亮它；标志嵌进场景不是盖上去。
- Igloo Inc（brand，5）3D 雪景占满，冰砖缝漏光是唯一亮点，文字退成等宽小标注。**换题**：选一个母题材质统一整站，所有条目都是"装在这个世界里的物件"。
- Lando Norris（personal，5）近黑底上一个荧光色头盔，字标小到当署名。**换题**：找你的"头盔"，一个能代表身份的实物，一个高饱和色，其余全暗。
- Opal Tadpole（product-launch，5）深灰底，手指间夹着产品，肤色和金属是唯一光点。**换题**：用真实的手做尺度和温度，产品换成你的工具或凭据。
- Terminal Industries（product-launch，4）黄昏、车灯、货运场站，底部渐变压暗给标题。**换题**：你的现场在哪个时辰最像自己，就用那个时辰的光。也见 1.3。
- Persepolis Reimagined（culture-museum，5）低机位、暖光、前景遮挡，像剧照；首屏只有场景和一个入口动作。**换题**：先拍"场景本体"，说明藏到进入之后。

### 1.2 真实现场与人

适合：团队、招聘、服务、工程、任何靠"这些人在哪里、为谁工作"成立的身份。

- Exo Ape（studio-home，4）暮色建筑实景上压一个超大出血单词。**换题**：实景换成你的现场（客户大楼、车间、机房），单词换成你们的动词。
- Locomotive（studio-home，4）满屏人像加一层只属于本行业的处理（像素带遮眼）。**换题**：人像不动，处理层换成你行业的痕迹（标注、扫描、批注），不能只是蒙版。
- Pangram Pangram（product-launch，5）每款产品一张满幅实景照，名字就是标题。**换题**：每个案例或场景一张照片一个名字，页尾用密度显示实力。
- Floema（brand，4）首屏只有一句话和留白，第二屏换成满幅户外实景。**换题**：先笃定地说一句，再用一整屏现场证明。
- Shopify Renaissance Edition（product-launch，4）油画母题贯穿到 404，目录叠在画面空隙里。**换题**：给你的题材找一个有出处的母题，所有边缘页同一母题。
- Palantir Careers（参照 ref-38，未评档）身份靠真实现场和岗位分工成立。**换题**：先写清"在哪、对谁、干什么"，再谈画面。目前唯一和驻场工程师同类的参照。
- basement.studio People（参照 ref-39）黑场、大字、真人。**换题**：没有现场照片时，用人和字，不用 3D。
- Teenage Engineering（参照 ref-41）一张照片交代地方、光、材质，字压在暗部。**换题**：挑一张能说明整个世界的照片，而不是一组好看的照片。
- Pentagram About（参照 ref-42）统一影像处理加网格，名字加城市就交代了分布。**换题**：团队页的人像先统一处理，再加一个只属于你们的字段。

### 1.3 现场之上叠一层技术

适合：软件改造实体运转、测量、数据服务、"看见了现实"的产品。

- Terminal Industries（product-launch，4）真实卡车被叠上线框扫描，现实到数字化的一瞬。**换题**：照片换成你改造的那个现场，线框只连到你改过的地方，一处。
- Lidar Drone Scanning（参照 ref-02）扫描线扫过真实地形，滚动推镜头。**换题**：扫描的对象换成你的现场，扫描结果换成你交付的东西。
- The Other Side of Truth（story-editorial，5）超大裁切字母加极小正文，首屏放真实实时数字。**换题**：找你题材里真的在走的数字（第几天、还剩几小时、多少次上线），放进首屏。
- Dropbox Brand（brand，4）每块色块自带表达内容的示意图形。**换题**：说明类页面每个维度一块，图形本身表达内容，不配图标。
- Chladni（参照 ref-14）物理模型生成图形，滚动推进讲解。**换题**：有真实模型或数据才用，没有就不要画"看起来像数据"的东西。

### 1.4 物件与工作台微距

适合：产品、工具、硬件、工作室手艺。注意：对服务和团队类题材，这一簇容易变成"办公用品静物"（本仓库 2026-10-21 实测，手账拼贴被用户评为"矮子里拔高个"）。

- Oryzo AI（product-launch，4）杯垫被当精密仪器拍，工作台、刻度、侧光长影。**换题**：只在主物真的是一件物时用；文案口吻和画面严肃度做反差。
- Lusion v3（studio-home，5）圆角深框里一堆亮面塑料物件，文字留在框外。**换题**：2 到 3 种颜色一种物件，靠材质和光拍好。
- Noomo Agency（studio-home，5）3D 物件穿插在字母之间，字和物同一空间层。**换题**：把你的物件放进文字层次里，一部分在字前一部分在字后。
- Mana Yerba Mate（product-launch，5）每个口味一整屏颜色一组角色，罐子位置不变。**换题**：章节切换时世界整体换，主物不动。也见 1.6。

### 1.5 纸、印刷与文字秩序

适合：有观点的文字、报告、原则、档案、没有好照片但有好话的页面。

- AIM Kharkiv（culture-museum，4）字标做成建筑体块，黑加暖灰两色，像印刷海报。**换题**：把你的名字画成页面里最大的几何块。
- Akaru（studio-home，4）窄体黑字标加糖果色竖栏，页尾反色裁切呼应。**换题**：一个压缩字体的字标加彩色分区栏。
- Sculpting Harmony（story-editorial，4）标题撑满视口宽，橙底黑线稿，等宽小字加大字加衬线正文三层。**换题**：信息密集页也能有海报感，靠三层字的分工。
- Synchronized Studio（studio-home，5）超大衬线压在有光泽的塑料膜上。**换题**：没有好照片时，一种有声音的字加一种真实材质（纸、膜、布），不要平涂。
- Linear Careers（参照 ref-40）原则写成编号短句，像团队自己的话。**换题**：中段靠文字的声音延续首屏，不靠装饰。
- Neutomni、Kinoria（参照 ref-12、ref-10）粗犷编辑式加复古界面；暗房颗粒。**换题**：只借颗粒与排印，不借怀旧壳。

### 1.6 平涂插画与角色世界

适合：消费品、游戏、面向大众的活动。对工程与服务类题材，角色容易被字面化（本仓库 GPT r6 的小人被用户评为"猎奇"）。

- Don't Board Me（brand，5）入口先弹一次球，红白粉三色，超大窄体字压图。**换题**：找一个与业务有关的小动作当入口。
- Messenger / Abeto（game-experience，5）标题像实体积木盖在小星球上，字与世界同材质。**换题**：先造完整小世界，按钮缩到角落。
- Ponpon Mania（story-editorial，4）拱门遮罩开窗，三四种饱和色统一全部插画。**换题**：异形遮罩和受限色盘。
- KPR（game-experience，5）半边脸铺满，标题阶梯式压在脸上，加 HUD 线框。**换题**：需要"人和口号同屏"时用。
- Zentry（game-experience，4）极粗压缩体钉在对角，图切成斜梯形窗口。**换题**：标题放对角，不居中。
- Dropbox Brand 的角色插画、Santioni Spirits（参照 ref-26）手部动画。

### 1.7 可走进的空间

适合：工作室炫技、展览、园区、有空间结构的内容。手机弱网慎用。

- Bruno Simon（game-experience，4）名字是场景里可被车撞到的物体，黄昏配色统一。**换题**：先统一在一个时辰的光下，再放玩法。
- Unseen Studio（studio-home，4）一张完整 3D 超现实场景，粉色统一，标题像场景里的招牌。
- Active Theory v6（studio-home，4）作品是空间里的玻璃板，不是卡片网格。**换题**：列表做成同一空间里的物件。
- Why Zero（product-launch，4）荧光绿 3D 手戳破窗口，常驻底部操作条。**换题**：一个角色贯穿全站并越出容器。
- Igloo、Messenger 也见 1.1、1.6；Overworld Audio、Edolus（参照 ref-01、ref-04）。

### 1.8 滚动即时间轴

适合：有先后顺序的过程（接单到上线、一天的工作、一个产品的展开）。是形态不是画面，首屏仍要从上面的簇取。

- Persepolis、Lando Norris、Opal Tadpole、Floema、KPR：滚动驱动镜头、物体与文字按章推进。Apple、Heron AI（参照 ref-16、ref-13）。

## 2. 换题公式

拿定一条案例后，写四行再动手：

1. **帧不变**：它让人停住的那一张构图照用。
2. **动法照搬结构**：它入场时什么从哪来、滚动时什么随进度变、什么由视频或 WebGL 接管，逐项写出"它的 X 换成我们的 Y"。卡车横穿换成什么在横穿，点云扫过换成扫什么，相机推进换成推向哪。动法写不出来，说明没看过它动，回去录。
3. **跟手照搬机制**：指针照亮、跟随、磁吸、变形，机制照搬，被照亮和被带动的东西换成现场的。
4. **名词全换**：地方、光的时辰、物件、人、数字，全部换成题材自己的。一个都不能留原案例的。
5. **光与色场从自己的现场取**：不沿用案例的色，问"我们的现场在那个时刻是什么颜色"。
6. **三处必须不同**：写出并排时一眼能说出的三处差异。写不出三处，换一条案例。

### 2.1 动法怎么做出来：对照机制示例

每种动法在 `examples/mechanisms/` 里都有能跑的单文件示例，复制机制，换皮肤。给执行代理的简报写"必须做到这三个动作，各用哪个机制"，不写"不做"清单。无 GPU 的机器只影响这边的验证截图，不影响交付给用户浏览器的东西；验证用 `capability-tiering` 的 static 档截图加代码核对。

| 参考站的动法 | 机制示例 |
|---|---|
| 实物横穿或相机推进整屏（Terminal 的卡车、Persepolis 的入场） | `scroll-camera-path`、`pinned-3d-scrub`、`image-sequence`（视频帧序列随滚动） |
| 现实变成数字：点云、线框、扫描线从一侧扫过 | `instanced-field`（点阵）加 SVG 线框叠层；`depth-parallax-image`（照片按深度分层位移） |
| 指针照亮暗处、浮雕随指针显现消失（Immersive Garden） | 自定义 radial mask 跟指针（CSS `mask-image` 或 canvas 2d），`fluid-ink-pointer`（指针拖出痕迹） |
| 固定舞台分章，文字随进度切换 | `scroll-story`、`lenis-webgl-sync` |
| 整屏图块切换、章节编号随之更新（Floema） | `scroll-story` 加 `cross-doc-view-transition` |
| 字逐个入场、沿路径滚动（Unseen、Synchronized） | `splittext-kinetic`、`variable-font-axis` |
| 视频接动画 | `<video autoplay muted loop playsinline>` 作底，ScrollTrigger 驱动叠层；见 `lenis-webgl-sync` 的单循环写法 |
| 全屏着色器背景、流体、噪声 | `fluid-noise`、`mesh-gradient`、`raymarch-backdrop` |

## 3. 不雷同三问

1. 遮住标题，换成别的行业还成立吗。成立就不是方向，是壁纸，淘汰。
2. 和案例并排，一眼能说出三处不同吗。动起来之后也要能说出：同一个动法，动的东西和落点必须是我们的。
3. 和我们自己用过的手法并排（`node toolbox/lib.mjs anchors --where group=low`：大字雕塑字、空底 3D 色带、照片压字加蒙版、3D 字加小人；另有台灯照片、手账拼贴两版未入库），重复了吗。
