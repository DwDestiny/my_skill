## 1. 氛围

### 1.1 主题盘点与点子

| 项 | 内容 |
|---|---|
| 主题盘点 | 工位与门架（地点）。每步留下的一个文件，一张张叠起来（材料）。三选一卡片、方向单、截图集、证据索引（印刷物）。发牌：一次发 3 张，两两至少 3 个轴不同（仪式）。盲评 1 到 5 分，门槛 3 分（数字）。检查点，默认值检查命中 2 项退回（约束）。委托人点头两次（动作）。`deal.mjs`、浏览器截图、盲评会话（工具）。 |
| 点子 | 页面是一台八工位的叠片机：一张写着原话的纸从左端进入，每个工位往上加一层透明叠片（这一步留下的文件）。八层压实以后，从右端出来的就是一张做过设计的页面。S3.5 是半厚的工位，检查点是黄色夹具。 |
| 情绪词 | 精确：所有数字有刻度，所有对齐有基线，不用纸纹、墨迹、印章。透气：舞台外是大块铝灰空白，不用满屏粒子，文字不压在图上。克制：全页只有一个"响"的时刻，黄色只出现在当前站与夹具合上的瞬间。 |

换题检查：换成别的行业，"八层文件叠成一页""半步工位""四个黄色夹具"都不成立。

### 1.2 页面形态与幕表

本页按四阶段讲流水线；叠片机的八个工位沿用评测页的历史划分，与四阶段不一一对应，页面不展示这个对应（缺口见 `blueprint.md` 信息缺口）。

形态：P03 固定舞台换内容（Sticky Stage）。不是纯瀑布流的理由：舞台章是"左文右机"，阅读章各有自己的版式（控制台、护栏板、铭牌），s2 与 s4 的滚动直接驱动机器状态，顶栏 7 个章名锚点可跳章。

| 幕 | 对应章 | 相机或舞台状态 | 视觉主体 | 停留方式 |
|---|---|---|---|---|
| 1 | s0 首屏 | 整机 3/4 侧视，八层叠片悬在机身上方，加载后落下压实，压实后层间留 0.01 间隙加亮边，八层仍可数；成品页在出料托盘上立起朝向观众 | 叠片机 | 滚动经过，1 屏，不 pin |
| 2 | s1 成品 | 出料托盘转到读者面前，5 张成品截图从叠放展开成一排 | 出料托盘与成品页 | 滚动经过，2 屏，不 pin |
| 3 | s2 八步 | 整机正侧视，相机沿机身推轨，压实的页面逆向拆回八层，每过一站拆出一层并标站名，夹具依次合上 | 八工位与八层叠片 | pin 3 屏，scrub |
| 4 | s3 点头 | S3 与 S3.5 工位近景双帧，夹具从张开到合上（一次性机器动作）。无实时渲染区 | 控制台面板与夹具 | 滚动经过，1 屏 |
| 5 | s4 防模板 | S3 工位特写，发牌口吐出 3 张方向卡，第 4 张（使用史里的组合）被推进废料槽并划线 | 发牌口与方向卡 | pin 1.5 屏，scrub，加 0.5 屏滚动经过 |
| 6 | s5 边界 | 无 3D。机身侧视，4 块护栏翻开，露出 4 块禁区 | 机身侧视与护栏 | 滚动经过，2 屏 |
| 7 | s6 缺口 | 无 3D。机身铭牌，5 行检验记录，未测与缺口用不同形状标记 | HTML 铭牌 | 滚动经过，1 屏 |

### 1.3 表面决定

| 维度 | 决定 | 数值或参照 |
|---|---|---|
| 材质 | 金属：阳极氧化石墨色机身、拉丝铝门架。第二材质：透明亚克力叠片（3D 内的透射材质，不用 CSS 玻璃）。 | 石墨 `metalness 0.9`，`roughness` 面 0.35、倒角边 0.2。亚克力 `transmission 0.9`。1 个环境贴图（`RoomEnvironment` 生成）。 |
| 光 | 单侧光（左上主光）加一条扫描光 | 方向光加环境贴图。扫描光是 2 px 的 `clip-path` 揭示线，只在章标题入场与 s2 的 S6 站出现。 |
| 空间 | 3D 场景加固定舞台 | 全页 1 个 `WebGLRenderer`，`setScissor` 分 3 个区域：A 首屏与 s1，B s2，C s4。接触阴影范围 30x8，不透明度 0.30，模糊 1.5。 |
| 图像 | 3D 模型（three.js 程序化）为主，kind=mechanism。自有截图作成品页，kind=data。SVG 自绘图示，kind=mechanism。image-gen 只作方向单里的目标板，不上页面。 | 成品页必须是真截图，不能生成冒充。资产清单见 `assets/generated/ASSETS.md`。 |
| 配色 | 单色结构色 `mono-structure`。底：冷灰最浅档。面：冷灰第二档。正文：冷灰最深档。强调：工程蓝（色相 212 附近）。状态：成功绿、警告与当前站黄、错误红。舞台底用有色深灰，不用纯黑。灰阶色相跟随主色。 | 见 3.1 令牌 |
| 颜色归谁 | 框架。页面没有外来内容图像，色彩只服务流程本身 | 框架灰阶加工程蓝。黄只标当前站这 1 个状态 |
| 拿走 | CSS 玻璃与模糊。接手者：3D 场景内的透射亚克力 | 只作用于框架层。签名时刻与舞台不拿走 |
| 边角 | 0 px：面板、顶栏、截图。2 px：顶栏锚点、按钮、控件。6 px：出料托盘。50%：圆点。11 px：仅开关轨道一处。（按页面反推） | `--radius-0: 0`、`--radius-1: 2px`、`--radius-2: 6px` |
| 透明度与模糊 | 仅两处半透明：顶栏下的工位剪影 `opacity: .35`（不接收点击），亚克力退路 `opacity: .35`。揭示用 `opacity` 0 到 1，260 ms。不使用 `backdrop-filter`，页面里只有一处说明文字提到它。（按页面反推） | 不透明度范围 0.35 到 1 |
| 动效气质 | 沉浸 | 在动的东西：叠片机的八层叠片、相机、夹具、护栏、方向卡。何时动：首屏加载后 1.3 秒内落下压实，s2 与 s4 随滚动 scrub，s3 与 s5 滚到时各做一次。占屏：舞台章画布约 58% 视口，签名时刻 1.3 秒内最多占全屏 60%。文字全在实色面板上，不被画布压住。 |

### 1.4 签名时刻与禁用

| 项 | 内容 |
|---|---|
| 签名时刻（全页 1 处） | 幕 1（s0 首屏）。加载后 1.3 秒内，悬在机身上方的八层透明叠片自上而下依次落下，错开 80 ms，同时运动不超过 5 层，压实后页面立在出料口，表面亮出上一个成品的首屏截图。表达的点："页面是八步留下的八个文件叠出来的"。s2 用同一物件反向拆开，同一手法全页 2 次。 |
| 禁用清单（5 条，≥2 条引用上一项目的具体决定。使用史为空时写“首次使用，不适用跨项目比较”） | 1. 不用"相机在一张大图纸上平移和缩放"（P01）。上一项目 mixed-01 用过。本页镜头固定，物件转向读者。 2. 不用印章、朱印、墨迹渗开类签名时刻。上一项目的签名时刻是"章落定渗印"。 3. 不用纸纹、颗粒、CSS 玻璃，不用 ZCOOL XiaoWei 与 IBM Plex Sans Condensed。上一项目用过。 4. 不用近黑底加单一霓虹辉光（`dark-neon`）。强调只有当前站黄，黄只表示当前站。 5. 不把八条机制、七个检查点、21 个示例排成同款圆角卡网格或原样表格。表格只进折叠，正文用机器的部件承载。 |
| 组件禁用 | `rows-02`、`footer-01`（上一项目 mixed-01 用过。本页 S5b 的 `rows-02` 是 E2 自己改写后再用，新项目不要照抄）。 |
| 参照（亲核） | 无亲核。4 个参照均未访问，只存 URL：oryzo.ai（首屏一件物体的渲染，背景无缝单色）、apple.com（产品拆解随滚动 scrub，文字固定在一侧实色区）、chladni-plate-experiment.vercel.app（一个物理模型随滚动逐章变状态）、drone.riotters.com（扫描线式视觉）。 |

### 3.2 动效规则

| 项 | 规则 |
|---|---|
| 气质 | 沉浸。叠片机的八层叠片、相机、夹具、护栏随进入、滚动或点击而动，舞台章画布约 58% 视口。 |
| 入场 | 每章 1 种。舞台章：机器动作开场（落片、推轨、发牌）。阅读章：扫描线揭示，一条 2 px 主色线从左到右揭示标题与首段。转场系统全页只有"扫描线揭示"1 个。 |
| 滚动驱动 | s2：相机距离随 pin 进度从 18.6 缩到 9，fov 不变，pin 300vh（约 8 步各占 37.5vh）。s4：发牌 pin 150vh。s1：5 张成品页用 `css-scroll-timeline` 从叠放展开成一排。顶栏当前章底线随章切换。 |
| 反馈 | 悬停、焦点：顶栏锚点底线 2 px 从 0 揭示到 100%，220 ms，`cubic-bezier(.2,.7,.2,1)`。按下：背景改 `--g2`。展开折叠条：160 ms。一次性机器动作：夹具合上 400 ms `ease-out`，落片每层 120 ms，护栏翻开一次后停在终态。 |
| 签名时刻 | 全页 1 处：首屏八层叠压，1.3 秒内完成，错开 80 ms，同时运动 ≤5 层。首屏时序：H1 可读 ≤0.8 s，模型就绪后最晚 2.0 s 开始叠压，超时改为首次滚动触发。 |
| Reduce Motion | 全部退到静。叠片机显示已压实、已出料的一帧。夹具显示合上，护栏显示翻开，s2 显示 8 行竖排站点，s4 显示 3 张卡平铺加 1 张划线卡。平滑滚动改原生滚动。 |

浮夸度边界（S2 与 S4 的 pin 合计 4.5 屏，低于 5 屏）：无无限循环动效，无闪烁，文字不压在画布上。
