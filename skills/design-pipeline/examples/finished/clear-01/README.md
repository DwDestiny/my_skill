# clear-01 · 社区活动报名小程序三页原型（公告栏）

来源：评测任务 E3（`evals/E3/`），2026-10-16 走完 S0 到 S6。题材与任何真实项目无关，所有活动、地点、人数都标"示例"。

| 项 | 值 |
|---|---|
| 档位 | `clear`（清晰优先，1 项克制的材质卡 `paper-object-stage`） |
| 载体 | `wechat-mini` HTML 平替，390×844，导航 44 px，胶囊占位，不画外框，只做浅色 |
| 页面形态 | P11 页面栈，5 幕：列表、详情、登记、凭证、取消确认层。hash 路由 `#/list`、`#/detail/:id`、`#/signup/:id`、`#/signup/:id/done` |
| 点子 | 服务站门口的公告栏：红纸日期条、签到表签名格、号码小票 |
| 签名时刻 | 成功态小票从 4 px 墨缝出票 720 ms，一次。Reduce Motion 直接显示 |
| 盲评 | 两人各 3 分，取低 3（`clear` 门槛 3） |
| Fable | S3 改后过门，S3.5 改后过门，S6 第 1 轮 3 分改后过门，修改轮 4 项必改全部核到 |
| 依赖 | 无。单文件，系统字体栈 |
| 本机未验 | 真机微信字体与按下态、打印预览看图、同行人数上限（原型值） |
| 截图 | `shots/`：`390-list.png`、`390-detail.png`、`390-signup.png`、`390-done.png`。S6 盲评与可区分性并排用 |

## 打开

```bash
python3 -m http.server 8130 --directory examples/finished/clear-01/page
```

浏览器开 `http://127.0.0.1:8130/#/list`，视口 390×844。

## 不可照抄的部分

1. 红纸日期条分组是"按日期看活动"这一内容结构的解。按类别或按地点的列表不能沿用红条。
2. 小票两层投影加锯齿齿孔是"凭证"语义的材质。没有凭证的流程（如问卷）不能用小票收尾。
3. 17 px 正文加 44 px 编号的字号表是给老年受众定的。面向年轻居民或后台人员的页面不应直接搬 17 px 底线。

## 可借的部分

| 位置 | 可借 |
|---|---|
| 令牌块 | 一色一义的色板（红只给日期条，墨色按钮，`--press` 按下态），字号表 14/17/22/28/44 |
| 列表段 | 同日多场合并在一张日期条下，`.day + .day` 4 px 板底缝分张，sticky 日期条 |
| 详情段 | 签到表：4 列格，序号加静态手写折线 SVG，剩余格虚线边 |
| 登记段 | 横格纸铺到底栏，摘要搬进横格行，空线 ≤3 条 |
| 凭证段 | 三段小票（主票、存根、存根联），齿孔用 `radial-gradient` 遮罩，两层投影 |
| 路由 | hash 路由、24 px 220 ms 页面 push、提交 `replaceState`、取消确认层焦点回退 |
| 打印 | `@media print` 每页 `break-before: page`，隐藏胶囊与底栏，红条 `print-color-adjust: exact` |
