# UI 视觉方向

本阶段可由用户直接调用，也可由 [$ui-delivery](../ui-delivery/SKILL.md) 串联。使用本阶段实际输入即可；缺少上游文件时写明假设与限制，不伪造上游已完成。

- **目标**：帮助用户选择或明确授权可执行的视觉方向，且保护交互结构不被视觉提案暗改。
- **最小输入**：需设计的页面与内容、已定交互结构、品牌/参考资产或用户明确风格要求；没有交互稿时保护用户已知行为并注明缺口。
- **输出**：direction-options.md、style-decision.json，按请求交付实际图片候选；selection.by 只能是 user 或 authorized_agent，且代选必须记录明确授权。

## 工作要求

帮助用户选择或明确授权可执行的视觉方向，且保护交互结构不被视觉提案暗改。按 [阶段工作流](references/workflow.md) 执行。选择记录遵循共享契约；只有完整套件工作区才创建阶段快照。

## 失败回退

要求图片探索但生成/查看能力不可用时必须标记 blocked；未获授权时保留候选，不定稿。

## 验收标准

图片候选确实可查看且对应页面状态；方向有实质差异；授权依据可追溯。
