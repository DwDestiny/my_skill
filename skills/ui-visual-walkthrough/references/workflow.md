# 视觉走查 · 工作流

## 0. 前置输入

- 可运行的目标（本机 dev server 或预览地址）+ 分支/commit 号
- 约定视口：默认桌面 1440×900、移动 390×844
- 账号态：若页面需要登录，确认可用的演示账号/登录方式
- 输出位置：报告 markdown + 同级截图目录

## 1. 同步与启动

1. 同步到约定的最新版本（记录 commit SHA，报告头部必须写）。
2. 安装依赖、启动 dev server，确认 HTTP 200。
3. 记录运行环境：端口、视口、登录身份、浏览器/工具。

## 2. 已有文档与路由盘点

1. **先读已有审计/设计文档**：仓库里若已有视觉审查报告或设计基线，全部读完再动手——承接上轮未修项，不重复报已修项；报告里注明与前轮的关系。
2. **路由枚举以代码为准**：从路由表/router 文件枚举全部路由；文档（README 等）声称的入口要实测，不一致本身是 issue。
3. **参数路由先取有效 ID**：查种子/mock 数据拿真实存在的 `:id`；无效 ID 落的空态不计入缺陷。
4. 登记覆盖表：路由 × 视口 × 状态 三轴，逐项勾选。

## 3. 逐屏取证

每页：导航 → 等首屏稳定 → 视口截图 → 分段滚动截图（见「滚动坑」）→ 必要时整页截图 → 对照检查清单逐条过目（见 checklist.md）。

命名约定：`NN-页面-区块.png`（如 `03-market-全部应用.png`），编号与报告目录一致。

### 滚动坑（实测教训）

- **平滑滚动**：`scrollTo` 可能是动画，读 scrollY/截图前先 `setTimeout` 等 ~1s，确认落点到位再截。
- **reveal 动画伪影**：IntersectionObserver 驱动的入场动画会让 fullPage 截图出现大段空白——那不是 bug。滚动到位重截取证；但「reveal 对无滚动场景（打印/截图/无 IO 环境）不友好」本身可记观察项。
- **内部滚动容器**：window 滚不动时查哪个元素 `scrollHeight > clientHeight`，可能是 div 滚动。

## 4. 实证探针（关键差异点）

截图之外必跑探针（playwright `browser_evaluate` 或 DevTools console），探针代码见 checklist.md：

| 探针 | 查什么 |
|---|---|
| 容器四要素 | 目标卡片的 computed `border/background/radius/shadow`——"像卡"不等于"是卡" |
| hover 覆盖层 | 枚举所有含 `:hover` 的非框架 CSS 规则；**重点找显式禁用规则**（`*:hover { transform:none }` 类覆盖层＝交互死区）；规则存在 ≠ 生效 |
| 真 hover | JS `dispatchEvent` **不触发** `:hover`——必须用真实 hover 工具（`browser_hover`）+ hover 中截图对比静止态 |
| 字号分布 | 统计全页文本节点 fontSize 分布，量化 ≤12px / <13px 数量与位置 |
| 截断检测 | chip/步骤条/标题的 `scrollWidth > clientWidth` 或纵向裁切（scrollHeight vs 行高） |
| 横滑溢出 | 锚点条/标签条可横滑但无渐变 mask/箭头/滚动条提示 → 桌面端同样算缺陷 |
| console 报错 | 每页切 error 档收集；非法 HTML 嵌套（如 `<p>` 内 `<div>`）会导致 hydration 报错 |
| 骨架一致性 | 页脚/导航在哪些路由存在——查代码里的路由白名单（如 FOOTER_ROUTES），详情页无端尾是常见缺口 |

## 5. 分级台账

- **P0 明确缺陷**：文字截断、裁切、console 报错、内容缺失、死链接
- **P1 体验硬伤**：该有容器无容器、该有 hover 无反馈、<12px 文本、单屏信息过载、CTA 被挤出首屏
- **P2 建议项**：信息架构单薄、占位死文本、文档与实现不一致、伪影风险
- 每条：现象（附实测值）→ 影响 → 修复方向 → 内嵌截图
- 「已验证正常项」单列一节并附对照图——证明覆盖到而不是没看到

## 6. 交付与根因

1. 报告头部：环境（版本 SHA、视口、账号态、工具）、覆盖表、分级汇总。
2. 尾部必写**系统性根因**：逐条现象背后的共同成因（令牌双轨、覆盖层禁用、骨架白名单、缺单一设计源等），并给出收敛顺序建议。
3. 与既有审计/规范文档建立引用关系，不制造平行台账。
