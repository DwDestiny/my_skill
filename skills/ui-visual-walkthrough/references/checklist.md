# 视觉走查 · 全维检查清单与探针

结构：**S0 审美定调（先判立场）** → 视觉体系 V1–V7 → 交互体系 I1–I5 → 技术卫生 T → 分级口径。

每条 issue 引用维度编号（如 V2-3、I4-2），判定均可实测或截图佐证。

---

## S0. 审美定调（开查前必做）

先回答三个问题并写进报告头，后续判定都引用它：

1. **边界立场**：项目是弱边界（hairline/微差底色）还是强边界（实卡/投影）？**弱边界 ≠ 无边界**——两端都判：裸排缺承载判丑，厚边框强投影越界同样判丑。
2. **色彩立场**：强调色是哪个、几枚？语义色（成功/警告/危险/info）是否成体系？
3. **密度立场**：内容型（密）还是营销型（疏）？同站混用要有规则。

若项目有设计令牌/基线文档（tokens.json、design-system.md、master-reference 类），先读它校准数值，再按本清单判。

### 容器档位（边界立场的可执行判定）

| 档 | 实测特征 | 判定 |
|---|---|---|
| 裸排 | border/bg/shadow/radius 四项全空 | ❌ 缺承载 |
| hairline | 1px 浅色边 或底色微差 + 充足内边距 | ✅ 信息流/行内分组/阅读内容 |
| 轻卡 | hairline + bg 微差；或 bg + whisper 投影（blur≤3、α≤0.05）；radius 12–16 | ✅ 可比较/可操作实体的标准形态 |
| 中卡 | 实底/深底/明显投影 | ✅ 仅限 hero、深色沉浸卡、CTA 重点位 |
| 重卡 | 厚边框、强投影、描边+投影叠加 | ❌ 越界（强边界项目除外） |

一句话：**让眼睛知道"这一块是一个东西"，但不让边框成为主角。**

## V1. 色彩

- [ ] 强调色全站是否单一贯穿（主 CTA/链接/选中态同一色相）；出现第二套强调色无语义分工 = 判丑
- [ ] 语义色分工稳定：绿=成功/通过、橙=风险/提醒、红=危险/超期、蓝=信息/官方——同色相不得跨语义混用（如蓝 tag 既表官方又表普通分类）
- [ ] tag/chip 色彩语义：同语义同色；**不得用颜色当唯一信息载体**（色盲可达）
- [ ] 深底卡文字对比度 ≥4.5:1（辅助 ≥3:1）；深底上嵌浅块造成"补丁感"判丑
- [ ] 渐变/玻璃拟态等特效是否只出现在 hero/重点位；大面积滥用 = 廉价感

## V2. 字体排印

- [ ] 字号阶梯可辨识：展示(≥28)/标题(18–24)/正文(14–16)/辅助(12–13)/micro(<12 禁用)；全页字号种类过多（>7 种）= 阶失控
- [ ] 字重层级：标题与正文、label 与 value 有明确字重差；「字段名加粗+值接排」连续 ≥3 行 = 简历式堆字段，判丑
- [ ] 正文行高 1.5–1.75；行长 45–75 字符/行；超宽行长判丑
- [ ] <12px 禁用于正文（仅图标辅助/legal 可）；连续大段 <13px = 密度过载
- [ ] 孤字换行（行尾单字掉行）、中文与数字间空格、中英混排一致性——细节 P2
- [ ] 截断：任何横向 ellipsis / 纵向裁切需有 aria-label/展开/滚动兜底；无兜底 = P0

```js
// 全页字号分布 + <13px 采样
const counts={}, small=[];
document.querySelectorAll('p,span,div,li,a,button,td,th,small').forEach(e=>{
  const t=e.textContent.trim(); if(!t||t.length>60||e.children.length>2) return;
  const fs=parseFloat(getComputedStyle(e).fontSize); counts[fs]=(counts[fs]||0)+1;
  if(fs<13&&t.length>4) small.push(t.slice(0,24)+' @'+fs+'px');});
({counts, smallSample: small.slice(0,15)});
```

```js
// 截断检测：横向 ellipsis / 纵向裁切

  text: e.textContent.trim().slice(0,20),
  clippedX: e.scrollWidth > e.clientWidth,
  clippedY: e.scrollHeight > e.clientHeight + 2}));
```

## V3. 空间与节奏

- [ ] 间距刻度成体系（常见 4/8 进制）；同站出现无规律间距 = 节奏失控
- [ ] 区块间留白 ≥ 卡片内边距；卡内 padding 同类一致（常见 20–24）
- [ ] 网格列间距统一；同类卡高度不齐时内容对齐策略合理（截齐/拉伸，不任其参差）
- [ ] 页面最大宽度有约束且居中；超宽屏不拉散
- [ ] 信息组之间（卡内上下组）有分隔节奏：间距、hairline 或底色块——紧邻无分隔的长串信息 = 堆叠

## V4. 容器与层级

- [ ] 实体档位判定（S0 表）：可操作实体 ≥轻卡；行内分组可 hairline；重点位才中卡；重卡越界
- [ ] 同性质实体档位一致；同区一半有底一半没有 = 语义不一致
- [ ] 承载语义可说明：卡片(实体) / 分隔线列表(连续阅读) / panel(分组容器) 三者分工明确
- [ ] 卡套卡 ≤2 层；内层与外卡视觉重量有差（内层更弱）
- [ ] 统计带/说明带数字与标签成组，不裸飘

## V5. 图像与图标

- [ ] 首字母徽章/图标与标题基线对齐；大小同系列一致
- [ ] 图标成套（同一风格族），不混线性/填充/手绘
- [ ] 占位图/默认图有设计感（纯色/纹理/首字），不是灰块或破图
- [ ] 图片比例、裁切、圆角全站统一；头像与内容图不同比例体系时有规则

## V6. 构图与引导

- [ ] 首屏：身份/价值 + 2–3 关键证据 + 明确 CTA，首屏可达（移动重点）
- [ ] CTA 视觉权重全站唯一最高；同屏多个"黑按钮"竞争 = 引导失焦
- [ ] 扫描路径自然（Z/F 型）；不出现视线断头路（右对齐孤元素无锚点）
- [ ] 空态有引导文案+去向；少内容区不留大白板
- [ ] 可横滑容器有渐变 mask/箭头/滚动条提示——桌面溢出同样算缺陷
- [ ] 死占位文本（"即将上线"类）不与真实按钮混排
- [ ] 孤标签/孤儿元素：游离、与内容无归属关系的 tag/badge

## V7. 动效

- [ ] 反馈调性与边界立场同调：弱边界项目用 `translateY(-2px)`/`scale(1.01–1.03)`/边框加深/底微变；禁重投影发光大位移
- [ ] 过渡时长 150–300ms；入场动画不阻塞内容可读（reveal 未触发时内容是否可用见 T-3）
- [ ] `prefers-reduced-motion` 降级存在（探针可测或代码确认）
- [ ] 同站动效语言统一：同性质元素同一反馈语法

## I1. 状态完备性（每件可交互物查六态）

hover / focus / active / disabled / loading / error（另有 empty/success 针对列表与表单）。

- [ ] 每个可点元素 hover 有可感知反馈（实测见 I5）
- [ ] 键盘 tab 可达 + focus 环可见
- [ ] disabled 态有视觉区分且不误判为可点

- [ ] 列表空态 / 表单提交成功态存在

## I2. 反馈语法一致性

- [ ] 同性质元素同反馈语言：全站"可点卡"一种 hover 语法、"链接"一种、"按钮"一种
- [ ] **覆盖层检测**：整组禁用规则把某区 hover 置 none = 交互死区（规则存在 ≠ 生效）
- [ ] 令牌/规则双轨冲突：同选择器在两样式源定义不同值

## I3. 操作闭环（逐项真操作）

| 交互件 | 必测动作 | 判定 |
|---|---|---|
| 筛选/chip | 点击 → 选中态 → 列表实变（前后计数）→ 可取消 | 点击无响应/不变=P0；无选中态=P1 |
| 排序 | 切换 → 顺序实变（记录首项前后对比） | 不变=P0 |
| 搜索 | 输入提交 → 结果集变化；无结果空态 | 无结果态=P1 |
| tab | 切换 → 面板更新；选中态一致 | 内容不换=P0 |
| select 下拉 | 展开 → 选中 → 值回填 | 卡死/不回填=P0 |
| 按钮/CTA | 点击 → 路由/弹窗/状态变化 | 死按钮=P0 |
| 表单 | 输入 → 校验提示 → 提交反馈 | 无校验/无反馈=P1 |
| 分页/加载更多 | 触发 → 内容实增 | 不变=P0 |
| 弹窗 | 打开 → 可关闭 → 遮罩/焦点合理 | 关不掉=P0 |
| 危险/不可逆操作 | 触发 → 确认或撤销存在 | 无保护=P1 |

## 分级口径

| 级 | 定义 | 例 |
|---|---|---|
| P0 | 明确缺陷：截断无兜底/裁切/报错/缺失/死链/交互无响应 | chip「交…」、`<p>`嵌`<div>`报错、筛选点击无变化、死按钮 |
| P1 | 体验硬伤：承载失档（裸排或越界）、无 hover、超小字、密度过载、堆字段判丑、CTA 出首屏、反馈语法不一致 | 实体裸排、hover 死区、10.5px 正文、六行加粗字段大卡 |
| P2 | 建议项：架构单薄、占位文案、文档不一致、孤字换行、伪影风险、细节工艺 | 行尾孤字、"即将上线"死文本、aria-label 语义弱 |
