## 3. 试过、没达标的方向

记下来是为了不重复走。每条写现象和原因，不是禁令。

| 方向 | 发生了什么 | 原因 |
|---|---|---|
| 字符动画（彩色字符拼出生长的根系） | 用户评价"丑、呆"，弃用 | 色块太大、画面僵；抽象之后没有主体 |
| 生图方向板直接铺成整屏底图 | 成品是满屏照片压字，交互只剩滚动 | 图承担了全部氛围，页面没有自己的手法 |
| 用实物比喻画抽象方法（标本柜、抽屉） | 用户："用柜子表达这个逻辑不太易懂，比喻也不是很恰当" | 比喻增加了一层翻译；讲解图先直接画关系 |
| 撞色立体挤出大字加小人 | 用户："很垃圾，审美不在线，有些猎奇" | 配色与主物本身不美；评审模型给了高分，模型的审美排序与用户不一致 |
| 为套案例给题材编时间与场景（凌晨三点的现场） | 用户质疑题材被写偏 | 世界描述里有内容规划中没有来源的形容词 |
| 把一条流程的全部环节拼进一张拆解总板 | 用户："这个图不够精美……应该分开画，每个环节能否用一些精美的实物来代替，每个环节单独讲解，讲清楚一些" | 一张板装太多东西，每件都画不细，每个环节也讲不清 |

## 4. 在做的方向（方向已获认可，整页待评价）

### 实物线图讲解

讲一条服务流程时，每个环节画 1 到 3 件真实器具的线图，和该环节的说明排在同一个版面里。器具图手写 2D SVG：浅灰细线，四档明度，暖色纸底。

- 用户评价（2026-10-27，看过两张试样）："可以，就按照这种方式来规划整个页面吧，我觉得这种浅灰细线搭配淡黄色阅读感会更好，线色可以稍微重一点点"。
- 用户评价（2026-10-27，看过整页 v0.1）："布局过于刻板，上方画框 + 下方文字的形式非常僵硬，重新排版、重新设计整体的氛围，更加融合，画图的质量我是认可的"。画法认可，版式被否。融合版式（做法第 1 条）待评价。
- 收录还差：整页的用户评价、效果图、起手代码。

做法：

1. 器具和说明排在同一个版面，不用"上面图框、下面卡片"。图框把图和字切成两块，读者看完图要到下面找对应的字，图就成了配图。做法：
   - 器具不加框，直接摆在纸面上，像摆在一张工作台上。几件器具错落叠放，不排成等宽三栏。
   - 宽屏：台面在左侧停住（sticky），右侧说明逐段滚过。读到哪一段，对应的器具保持原色，其他器具变淡变灰，并从器具画一根细线连到这段说明的色点。
   - 说明不加卡片：色点加子业务名、衬线小标题、步骤链（本环节的步骤用荧光笔底色标出）、正文。信息缺口用红笔圈的问号标出。
   - 页面左侧留一条页边线，环节号和竖排的章节名挂在线上并停住，整页像一本带页边批注的笔记。其他章节也去掉方框，改用线、时间轴和引文。
   - 窄屏：器具按顺序竖排、左右错开，说明跟在后面，不画连线。
   - 平庸：上方一个带边框的图版，下方三张等宽卡片。好：左边一张不动的工作台，右边说明滚过，读到哪件器具就亮哪件，并连一根线。
2. 每个环节单独讲。全流程关系另用一张总览图（色带加连线），不在器具图里表达。
3. 画器具最好认的那一面，并画出它独有的部件。例：手持三维扫描仪画正面，宽扫描头上两只相机夹一个投影窗，下接手柄。只画侧面时剩一个头加一个柄，读者看成吹风机。
4. 外形说不清的东西（软料、有机形状），改画取它、装它的工具。例：耳印模是一团软料，画出来被看成鸭子。改画装印模材料的注射器和棉障后，读者一眼认得出。
5. 部件比例按实物定，不为构图拉长或压扁。曾被误读的例子：试镜架的镜腿画太长，像天线；鼻托画成一条弧，像皱眉；耳背式助听器机身太细又多一道弧，像香蕉加笑脸。
6. 自检：遮住标签看缩略图，问"这是什么"。答不出或答成别的东西，按第 3 至 5 条改。
7. 图内文字的视觉尺寸不小于正文的 0.8 倍。标签放在空白处，不压线。
8. 用 2D 线图，不做 3D 建模。大多数实物用 2D 线图已经讲得清，建模和渲染很占机器资源。
