## 1. 页面形态

已验证的形态是**滚动长页 + 一张固定全屏 WebGL 画布**。

| 章类型 | 底 | 光 |
|---|---|---|
| 舞台章（`class="stage"`，100vh） | 成对图 | 指针 + 巡游；可加吊灯 |
| 正文章 | 只有程序底纹 | 指针，空闲时缓慢漂移 |
| 签名章（外层高 400vh，舞台 `position:sticky`） | 成对图 | 滚动逐盏点亮吊灯 |

已验证页面共 7 章，4 章有成对图，3 章只有底纹。成对图章与正文章交替，读者不会一直在暗处找光。

## 2. 驱动

| 驱动 | 参数 | 说明 |
|---|---|---|
| 指针 | `follow` 0.91 | 光略慢于指针；`pointerdown` 也移动光，手机点按可用 |
| 空闲巡游 | `idleMs` 4000，`tourMs` 3200 | 有热点照热点，有吊灯照已亮的区，否则缓慢漂移 |
| 吊灯 | `setLit(n)`，最多 4 盏 | 签名时刻：读者在上一章只有一盏小灯，进入签名章后随滚动逐盏点亮，全页只有这一处多灯 |
| 键盘 | 页面自己实现 | 讲者用 ← → 或 PageUp / PageDown 按章翻 |

吊灯章的滚动映射（演示页 `lampScroll()`）：进度 10% 前 0 盏，之后每 19% 多亮一盏。

签名时刻要承载一个论点。已验证页面的论点是"一个人照不过来，分工才能照亮全部"：上一章光圈缩小（`lr` 20），这一章四盏灯接力亮起。

## 3. 换章

1. 底纹常驻，不随章节切换。
2. 场景图四边羽化（上 12%、下 16%、左右 4% 到 5%）。
3. 切到新场景时，旧场景图先在 0.6 秒内化回底纹，再在 0.9 秒内化入新场景图。
4. 墨迹场保留，光不断，光圈大小随 `ia` 平滑过渡。

平庸版：背景硬切，中间一帧黑场，墨迹清空。用户评价"突兀"。

## 5. 说明牌与计数

说明牌是读者照亮后得到的信息。写法：

1. 格式：编号 + 概念名词 + 一句判断。名词是物件代表的概念，不是物件本身。
2. 隐喻交给画面。画面已经画了悬空的网线，文字不再说"没接上"。
3. 写工作，不写人。不写抓包句（"员工没在用"）。
4. 没有真实案例时写通用判断，不编具体情节。
5. 一次只亮离光最近的一张，照过的留一个暗点。
6. 在逗号处手动断行，每行一个意思。

| 平庸（造场景） | 好（判断） |
|---|---|
| 屏幕：开通了工具，屏幕上仍是登录页 | FIG 03 使用　愿意尝试，工具还没进入关键任务。 |
| 档案柜：上个项目的资料没人接手 | FIG 05 延续　项目结束，下一个仍从零开始。 |

计数放在右上角："已看见 n / 5"。它告诉读者还有几处没照到，读者会主动去找。

说明牌的样式：1 px 暖色引线、8 px 暖色圆点、衬线编号、文字阴影代替底板。不用卡片容器与玻璃模糊。
