## 1. 两个 pass

| pass | 输入 | 输出 | 做什么 |
|---|---|---|---|
| ADV（平流） | 上一帧墨迹场、指针位置与速度、吊灯 | 新墨迹场（512×320，单通道） | 墨被卷曲噪声推着流动；向四邻扩散；按时间衰减；指针与吊灯处补墨 |
| SHOW（显示） | 墨迹场、底层图、揭示层图 | 屏幕颜色 | 墨迹浓度加 fbm 噪声后过阈值，得到揭示遮罩；遮罩边缘压暗并加暖色 |

ADV 每帧做的事，按顺序：

1. 用卷曲噪声算流速 `c`，加上指针速度 `mv`（只在光圈内生效）。
2. 从 `uv - 流速` 处取墨（反向平流）。
3. 自身 0.4 + 四邻各 0.15，得到扩散。
4. 乘保留比例 `dec`、减 `fd`，得到衰减。两者按真实帧时长折算，低帧率时痕迹时长不变。
5. 与指针光圈 `lamp*g`、四盏吊灯取最大值。

SHOW 每帧做的事：

1. 底纹：程序生成的暗色大理石纹，始终存在。
2. 场景图：按四边羽化与换章系数 `ia` 叠到底纹上。底层取 `pow(lum,1.35)` 混向冷灰蓝，揭示层乘 1.3。
3. 遮罩 `m = smoothstep(.22,.62, 墨 + fbm*0.38 + 细噪声)`。
4. 光边 `edge` 是遮罩的中段，压暗 12% 到 28%，再加一点暖色。
5. 加 2.5% 胶片颗粒。

## 2. 参数表

所有参数在 `LayeredReveal.defaults`，`mount()` 第三个参数覆盖。

| 参数 | 默认 | 调大 | 调小 |
|---|---|---|---|
| `inkRes` | 512×320 | 边缘更细、更贵 | 边缘更柔、更省 |
| `decay` | 0.993 | 痕迹留得更久；1.0 为永久 | 痕迹很快合上 |
| `fade` | 0.0012 | 淡墨更快消失 | 淡墨残留成雾 |
| `curl` | 0.0016 | 墨流动更明显、更乱 | 墨几乎不动，像硬光圈 |
| `push` | 0.6 | 快速划过时墨被甩出更远 | 光圈不受速度影响 |
| `thresh` | [.22,.62] | 两端都升：揭示区变小、边缘更硬 | 揭示区变大、边缘更软 |
| `edgeNoise` | 0.38 | 边缘更破碎，像宣纸洇开 | 边缘更圆 |
| `edgeDark` | [.12,.28] | 光边一圈暗线更明显 | 无暗线，像普通遮罩 |
| `baseMix` | 0.42 | 暗处更亮（投屏用 0.65） | 暗处更暗（0.2 时差别最明显） |
| `baseGamma` | 1.35 | 暗处只剩高光轮廓 | 暗处偏灰 |
| `topGain` | 1.3 | 光下更亮 | 光下更沉 |
| `follow` | 0.91 | 光更慢、更有重量 | 光紧跟指针 |
| 场景 `lr` | 10–20 | 光圈更小 | 光圈更大 |

## 3. 调参顺序

1. 先定光圈大小 `lr`：直径约等于一个热点物件的 1.5 倍。
2. 再定明暗差 `baseMix`：截一张光停在热点上的图，暗处与光下的差别要一眼可见。
3. 再定边缘 `thresh` 与 `edgeNoise`。
4. 最后定痕迹 `decay`。

一次只改一个参数，每改一次截一张图对比。

## 4. 换边缘质感

只改 SHOW 里遮罩与光边那四行，或 ADV 里补墨那一行。

| 质感 | 改法 |
|---|---|
| 烟 | `edgeNoise` 升到 0.6，`curl` 升到 0.004；光边加冷灰 `vec3(.6)*edge*.08`，去掉暖色 |
| 水波纹 | ADV 改成两张场交替的波动方程（`new = 2*cur - prev + c*拉普拉斯`）；SHOW 用波高的梯度偏移揭示层采样，产生折射 |
| 纸边燃烧 | `thresh` 收窄到 [.45,.5]，边缘变硬；`edge` 加橙红 `vec3(1,.4,.1)*edge*.6`，外侧再加一圈焦黑 `smoothstep(.3,.45,m)*(1.-m)` 压暗 |
| 油画笔触 | 补墨改成沿指针速度方向的拉长椭圆；fbm 换成按方向拉伸的噪声 |
| 擦开的霜 | 底层换成揭示层加模糊与冷白；`decay` 设为 0.999 以上，痕迹慢慢重新结霜 |
| 枯笔飞白 | 遮罩乘一张高频条纹噪声 `step(.4, n2(w*vec2(80,6)))`，只在边缘段生效 |
| 永久刮开 | `decay` 1.0、`fade` 0；补墨用 `max` 保持不变 |

先做首屏试样，确认质感后再全页使用。以上都是衍生，未在项目中验证。

## 5. 三层以上

1. SHOW 增加第三张纹理 `deep`。
2. 用墨迹浓度分两段：`m1 = smoothstep(.22,.62,k)` 揭示中间层，`m2 = smoothstep(.7,.95,k)` 揭示最深层。
3. 颜色 `col = mix(mix(base, top, m1), deep, m2)`。
4. 指针停留越久墨越浓，停住的地方揭得更深。

## 6. 性能

| 项 | 做法 |
|---|---|
| 画布分辨率 | `dprMax` 1.5；手机可降到 1 |
| 墨迹场 | 512×320 已够；手机可降到 256×160 |
| 浮点纹理 | 有 `EXT_color_buffer_float` 用半精度，没有就用 8 位（痕迹稍短） |
| 软件渲染 | 无头浏览器走 SwiftShader 时帧率低，等 2 秒以上再截图 |
