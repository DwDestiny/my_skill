# 设计手法库 · 索引

本插件只收在真实项目里做出好效果的手法。每个手法是一个目录，含效果图、手法卡和完整的风格化 skill。用户原话优先于本插件的任何规则。

## 1. 手法表

| 手法 | 一句话效果 | 适合 | 所需工具 | 子 skill |
|---|---|---|---|---|
| 叠图晕染 | 几层构图对齐的画面叠在一起，指针、灯或滚动推开一道水墨般的边，揭示下一层 | 宣讲页、品牌页、产品页、前后对比；要讲"表面之下是什么"的内容 | 生图（成对图）、WebGL2 | `design-techniques:layered-reveal` |
| 手绘风格化 | 用代码在有颗粒的纸上画钢笔线、彩铅和手写字，图与文字同色对应 | 讲解页、课程页、方法图、流程图；要让人看懂并记住关系的内容 | Canvas2D、开源手写字体（OFL） | `design-techniques:hand-drawn` |

每个手法的完整信息在它的手法卡：`${CLAUDE_PLUGIN_ROOT}/skills/<手法 id>/CARD.md`。效果图在 `${CLAUDE_PLUGIN_ROOT}/skills/<手法 id>/showcase/`，先看 `cover.webp`。

## 2. 选手法

1. 如果用户点名了手法（"叠图""晕染""探照灯""手绘""彩铅""手抄报"），直接调用对应子 skill。
2. 如果还没有内容规划，先做内容规划：受众、要讲清的 3 到 7 件事、每屏一句话。装了 `content-blueprint` skill 就用它。手法服务内容，先有内容再选手法。
3. 打开候选手法的 `CARD.md` 和 `showcase/cover.webp`，对照"适合"与"不适合"两行。
4. 问一句：读者在这个手法里做的动作（照亮、悬停、翻页），和要讲的内容有没有关系？有关系的手法优先。例如"表面之下藏着什么"适合叠图晕染，"几样东西之间是什么关系"适合手绘风格化。
5. 调用子 skill，按它的 SOP 做。子 skill 里有衍生变体表：同一手法可以换题材、换层、换笔，不只复刻已验证的那一次。

如果两个手法都不合适，告诉用户库里没有合适的已验证手法，说清差在哪里。然后给出 `${CLAUDE_PLUGIN_ROOT}/CANDIDATES.md` 里最接近的候选，或按用户的意思试做，并在交付时标明"未验证手法"。

用户问"有哪些手法"时，给出第 1 节的表和每个手法 `cover.webp` 的路径。能显示图片的环境直接展示效果图。

## 3. 工作方式

两个手法的成功都走了同一条路：

1. 内容规划。
2. 选手法，写一句"这页像什么、读者做什么动作、动作揭示或连起什么"。
3. 做首屏试样，给用户看。用户能打开的链接或截图都可以。
4. 按用户原话改。先判断原话违反了手法的哪条原理，再改。把原理、通用改法和原话写进该手法 `SKILL.md` 的踩坑节。
5. 做整页。
6. 截 1440 宽与 390 宽，每张图亲自看过，按该手法 `SKILL.md` 的验收标准逐条过。
7. 交给用户评价。用户评价记进该手法 `CARD.md` 的实践记录。

## 4. 收录新手法

一个手法同时满足下面四条，才进 `skills/`：

1. 在真实项目里用过。
2. 用户评价效果达标，记下原话与日期。
3. 有效果图（`showcase/`）。
4. 起手代码能在浏览器直接打开，依赖实测过。

收录步骤：

1. 复制一个已有手法目录的结构：`SKILL.md`、`CARD.md`、`agents/openai.yaml`、`references/`、`templates/starter/`、`showcase/`。
2. 按“通品”写 `SKILL.md`，不写成某一次作品的复刻说明：
   - **原理**：这个手法为什么能打动人。换任何题材都成立。
   - **方法**：从一个新题材推出画面的步骤，加至少两个不同题材的推演。
   - **验收标准**：每条写测什么、怎么测、过线是什么。
   - **踩坑**：按原理归类，用户原话作证据。
   - **实例**：已验证那次的参数只作起点，放在最后或 `references/`。
3. 在本文件第 1 节的表里加一行。
4. 在插件 `README.md` 加封面与一句话。
5. 从 `CANDIDATES.md` 删掉该条。

其他手法、外部 skill 与试过但没达标的方向，只记在 `CANDIDATES.md`，不进 `skills/`。

## 5. 文件

| 文件 | 何时读 |
|---|---|
| `${CLAUDE_PLUGIN_ROOT}/skills/<id>/CARD.md` | 选手法时 |
| `${CLAUDE_PLUGIN_ROOT}/skills/<id>/showcase/cover.webp` | 选手法时；向用户介绍手法时 |
| `${CLAUDE_PLUGIN_ROOT}/CANDIDATES.md` | 两个手法都不合适时；要收录新手法时 |
