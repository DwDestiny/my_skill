# 纸面

> 做到“改纸色、换纸面或颗粒不对”时读。

## 1. 一张高度场管全部质感

`HandDrawn.init()` 生成一张可平铺的高度场 h（0..1），再派生四张图：

| 图 | 公式 | 用在 |
|---|---|---|
| `bg` 纸面 | 纸色 × (1 + 左上来光 ·.07 + h 起伏 ·.05 + 大块深浅 ·.035)，加纤维短弧和杂点 | 页面背景 `--paper-img`、卡纸 |
| `tooth` 纸齿 | h < .47 处透明度升到 1（软边 .17） | 彩铅画完后 destination-out 擦掉，笔触只留在凸处 |
| `drop` 墨缺口 | h < .28（软边 .12） | `paperize`：墨线在深坑里断开 |
| `keep` 大字遮罩 | 1 − .3 × (h < .22 的程度) | HTML 标题的 `mask-image` |

因为四张图同源，彩铅颗粒、墨的断口、标题缺墨和背景凹凸落在同一批坑上。这是“像真的纸”的关键。

## 2. 对齐

- 每块画布用 `paperPattern(c, tile, cv)` 取纸纹：按画布在页面里的位置 (rect + scroll)·DPR 平移。多块画布和页面背景的颗粒才连得上。
- 背景 `background-size` 与遮罩 `mask-size` 都写平铺块的 CSS 尺寸（默认 512px）。

## 3. 换纸面

| 纸面 | 改法 |
|---|---|
| 牛皮纸 | paper 设 `[196,160,112]`，纤维增到 400 且偏深；墨改深棕 |
| 方格纸 | 在 `bg` 上再画 16 px 浅蓝格线（.15 透明），格线也过一次 `drop` |
| 黑板 | paper 设 `[38,52,46]`；粉笔用浅色彩铅（混合改 `screen`，tooth 反过来用 h > .53 的凸处）；擦痕用大块低透明白色彩铅 |
| 蓝图 | paper 设 `[28,74,140]`；线用 `#e8f0ff`，混合改 `screen`；高度场权重减半，蓝图纸更平 |

调参顺序：先看 2× 裁图里纸齿是否成团（太大调第一层格数），再看彩铅是否“落在纸上”（调 toothThr），最后看标题（keepMax 不超过 .3）。
