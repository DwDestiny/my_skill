# 画具

> 做到“调钢笔、彩铅、排线，或新增画具”时读。

## 1. 钢笔 `pen`

- 点列先按 4 单位重采样，每点沿法线按一维噪声摆动（jit）。
- 画两遍：主线（w，.92 透明）+ 复描（w/2，.45 透明，噪声相位不同）。复描让线有“笔走了两次”的厚度。
- jit：草稿感 .8–.9；干净的物件 .3–.4；排线内部更小。未完成的东西也用 .3，靠浅色表达未完成。

## 2. 彩铅 `pencil`

- 在包围盒里随机撒短笔触，同一次调用里角度一致（默认 −1.08 rad ± .1），`alpha(x,y)` 决定这里留不留笔触。深浅由密度 + alpha 函数给，不靠填色块。
- 先画到暂存画布，再用纸齿 destination-out，最后 multiply 落到目标画布。
- 叠色：同一区域先浅后深两次（例如面包先金黄、再压焦棕），第二次 alpha 只在暗面高。
- 角度、笔触长、密度跟着材质和明暗选（`principles.md` 第 6 节）。小物件用默认角度即可。
- 大面（天空、墙面、崖壁、地面）用一种颜色、一个角度铺满时，读起来像在下雨。改法：
  1. 按材质把大面切成几块或几层，每块一种颜色、一个顺着它走的角度。
  2. 明暗另叠一遍冷色，只落在背光处。
  3. 最亮的面（通常是天空）用长笔触、低密度，成片留白。
  4. 在 2× 裁图上看：能看出层次和走向，看不出一道道平行斜线。
- 已验证实例的大面参数见 `scenes.md` 第 2 节。

## 3. 排线 `hatch` 与四层

- 一组平行线，每根线沿走向采样，`tone(x,y)` 大于阈值才落笔；线位带两层噪声摆动，偶尔 1.5% 断笔。
- `HATCH_LAYERS` 四层：两层顺向（thr .16 / .42）、两层 ±.5 rad 交叉（thr .6 / .78）。tone 越高叠的层越多，深处自然更密。
- **随形**：angle 顺着形体走。色带顺着带；圆柱顺着长轴；竖面用 π/2；圆顶斜一点（−.35）；山坡顺坡（1.15–1.2）；崖口顺崖边。
- `hatchIn` 是单层版：一组平行线，`tone(x,y) > thr` 才落笔，`rag` 让分界参差、`wob` 让线摆动。场景里的背光坡、岩层线下阴影、云底都用它。
- 分档变深：给 `level(x,y,lr)`，线在档位分界处断开改墨色；用 lr（每根线的随机数）错开分界，起笔才不会齐刷刷。

## 4. 物件小件

| 函数 | 要点 |
|---|---|
| `ring` | 起笔收笔多画 6%，半径 ±5% 抖；填色取前 n−3 个点 |
| `tape` | 半透明，两头锯齿，上沿一道白色高光 |
| `paperCard` | 手裁边（每 10 单位抖 ±.8），影子按 DPR·k 手乘，纸纹缩放 1/DPR 再盖一层提亮 |
| `frame` | 钢笔边 + 内圈点（点距 9）+ 四角星 |
| `fadeDash` | 实段越来越短、空隙越来越长、墨越来越淡 |

## 5. 新画具（衍生，未验证）

| 画具 | 做法 |
|---|---|
| 马克笔 | 宽笔（8–14）、低抖动、两端各加一个更深的小圆（积墨），重叠处 multiply 自然变深 |
| 水彩晕染 | 多层低透明多边形，每层边缘噪声外扩；边缘再描一圈略深（湿边）；最后过 tooth 做颗粒沉淀 |
| 炭笔 | 彩铅改宽短笔触 + 高 tooth；用 destination-out 的软笔刷做擦抹 |
| 粉笔 | 浅色彩铅、screen 混合、断续更多；线周围撒少量粉尘点 |
| 逐笔画出 | 每条 pen 的点列按时间截断重画，或在画布上用 clip 从起点扫到终点 |
