# 情绪画面：从一句话到一幅画

> 做首屏、章节页这类“情绪画面”时读。原理见 `principles.md`。本文先写通用步骤，再给一个已验证实例和三个换题材的推演。

## 1. 步骤

1. **写概念句。** 读者看 3 秒要感到什么：落差、冲突、期待、转变。写成一句话。
2. **出比喻候选。** 用并置、断开、融合三种构造（`principles.md` 第 1 节）各想一个。每个写一句“为什么一眼能看懂”。推荐一个，让用户定。
3. **定世界。** 从题材推纸面、画具、版式语法（SKILL.md 第 2 节三问）。世界决定画里有什么：山谷、厨房、作坊、教室。
4. **小稿定构图。** 只画明暗块，不画线。决定四件事：平衡方式（对峙、对角、中心）、焦点位置、标题放在哪片浅区、深色压在哪里。可以用代码画灰块，也可以手写坐标。2 到 3 个小稿里选一个。
5. **分层。** 远、中、近三层，再加焦点。每层写下：颜色冷暖、线宽、细节多少。
6. **排细节。** 焦点处放结构细节，中景放一层颜色，外围画一小片就淡回纸里。列出焦点处至少三种细节来源：随形排线、多层叠色、结构细节、周围的东西。
7. **按顺序画。** 远到近、大到小、结构到纹理。实心物体先垫纸，再画。一层一块画布，要单独动的层才拆开。
8. **设计动效。** 入场顺序讲故事；常驻只动本来会动的东西；响应放在概念点上（`principles.md` 第 9 节）。
9. **手机重新构图。** 竖屏不是缩小横屏：标题仍在画里的浅区，主体移到下半屏，焦点保持清楚。场景参数集中在一个 `sceneGeo(vert)` 里，横竖各一套。
10. **验收。** 按 SKILL.md 第 6 节逐条看截图。

## 2. 已验证实例：合不拢的桥

用户 2026-10-27 评价：“这个标准可以了”。起手页首屏就是这一幅，文字换成了中性题材。

| 步骤 | 这一次的决定 |
|---|---|
| 概念句 | 两方各做了一半，却在中间接不上 |
| 比喻 | 断开：两岸各修半座桥，在河心一高一低错开。另两个候选（饱满面包与塌面包、咬不上的齿轮）被放下 |
| 世界 | 奶油纸、钢笔加彩铅、手抄报花边；山谷 |
| 构图 | 对峙：两岸两座半桥分量相当；焦点是河心断口；标题在两岸上方的天空正中 |
| 分层 | 天（太阳、云、鸟）→ 远山两层（蓝灰、灰绿）→ 两岸台地与松树 → 岩层崖壁、桥、峡谷、河 |
| 细节 | 焦点处：桁架斜杆、铆钉、桥面板缝、桥墩石块、桥头牌、小旗；崖壁：分色岩层、竖缝、卵石；外围：远山只在背光坡排线，四边淡回纸里 |
| 颜色 | 一方橙、一方蓝，桥头牌的字同色；红色只用在一句批注“接不上”和断口的圈上 |
| 动效 | 入场：天 → 地 → 两座半桥从两岸往河心画出 → 小旗 → 牌子 → 批注。常驻：水、旗三帧轮换，鸟两帧，云慢移。响应：悬停标题后半句或断口，断口出现手画圈；悬停桥头牌，字抖一下 |

参数（只作起点，换题材按画面尺度重推）：

| 项 | 值 |
|---|---|
| 逻辑画幅 | 横 1600×1000，竖 560×1000 |
| 线宽三级 | 外轮廓 1.4–1.9，结构 .8–1，排线 .6–.75 |
| 天空彩铅 | 角度 −.4，笔触长 32，密度 .036；标题周围的椭圆里淡到约 18% |
| 岩层彩铅 | 角度 −.14，笔触长 11，密度 .24；7 种土石色轮换 |
| 远景 | 轮廓线 .9–1、透明 .6–.7；只在背光坡排线；山脚擦雾 |
| 入场 | 天 1.1 s；地 1 s（延迟 .35 s）；半桥擦出 2 s（延迟 .9 / 1.05 s）；批注延迟 3 s |
| 常驻 | 水 1.2 s 一轮；旗 .66 s；鸟两帧 .72 s；云 24 s 往返 22 px |
| 响应 | 圈擦出 .6 s；逐字抖 .42 s，错开 30 ms |

## 3. 同一套步骤，换三个题材（推演，未验证）

下面三个推演说明这套步骤能迁移。每一格都由原理推出，不照搬桥。

| 步骤 | 烘焙课：“看得懂配方，做不好面包” | 地方史：“一条河养大了三座城” | 儿童科学：“月亮为什么会变形” |
|---|---|---|---|
| 比喻 | 并置：摊开的配方书上画着饱满的面包，旁边烤盘里是塌掉的那个 | 融合：河从画面一角流到另一角，河弯处长出三座城，河就是时间轴 | 不用比喻：概念本身是一个关系，直接画 |
| 世界 | 配方卡与厨房桌面；马克笔标题、水彩晕食材、钢笔勾线 | 牛皮纸、炭笔、两色套印 | 黑板、粉笔 |
| 构图 | 对峙：书与烤盘左右相对，焦点在塌陷处 | 对角：河从左上流向右下，标题在左下的空处 | 中心：地球居中，月亮绕一圈 |
| 分层 | 墙上挂具 → 桌面与面粉袋 → 书与烤盘 | 远山与天 → 河谷田地 → 三座城（越往下游越大） | 星空 → 轨道 → 地球与各相位的月亮 |
| 焦点细节 | 面包的割口、塌陷的褶皱、书页的配方插图 | 城墙、桥、码头上的船 | 被照亮的半边和看到的形状，用粉笔连线对应 |
| 颜色 | 金黄 = 书上的理想，焦褐 = 实际 | 赭 = 河，三座城各一色，与正文章节对应 | 白粉笔 = 光，黄 = 看到的形状 |
| 动效 | 常驻：热气三帧、面粉飘落；响应：悬停圈出塌陷 | 常驻：河水流动；响应：悬停一座城，城亮起并出现年份 | 常驻：星星闪；响应：悬停一个相位，粉笔圈出并连到地球上看到的形状 |
