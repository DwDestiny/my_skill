# 首屏场景

> 做到“首屏画面”时读。

## 1. 构图

- 首屏是一整幅铺满屏宽的钢笔场景，标题放在场景的留白里（演示页：左上标题，下方一张长桌贯穿全屏，右上挂杆补满留白）。
- 用一个深色主体平衡标题（演示页是桌面和书）。刻意画淡的元素（未达成的目标、烟）不算分量。
- 用户否过的构图：一张小卡片 + 一条线 + 一座小房子（“过于简单”）；标题一侧重、另一侧只有淡元素（“右侧太空，左侧太重”）。

## 2. 比喻

- 首屏可以用比喻，但要强：一眼能看出“落差”。弱：越走越断的路。强：书上的饱满面包 vs 烤盘里塌掉的面包；两岸各修一半却错开的桥；咬不上的齿轮。
- 先给用户两三个候选比喻，用户选了再画。

## 3. 细节密度

精细来自四样东西，每个主要物件至少有三样：

| 来源 | 演示页里的例子 |
|---|---|
| 随形排线 | 桌子前沿横排线、桌腿竖排线、面粉袋斜排线、擀面杖顺长排线 |
| 多层彩铅叠色 | 面包先金黄再压焦棕；桌面木色 + 板缝 + 木纹 |
| 结构细节 | 书的纸叠、书脊阴影、书签带；袋口的褶和扎绳；面包割口与裂缝；擀面杖手柄 |
| 周围的场景物 | 麦穗、洒出的面粉、碎屑、挂杆上的打蛋器 / 刮刀 / 汤勺 |

只靠线条抖动不算精细。

## 4. 物件写法

- 每个物件一个函数，在局部坐标（底边中点为原点）里画；`at(c, x, y, s, fn)` 平移缩放，并按 s^−.6 补偿线宽，缩小的物件线不会细到看不见。
- 要交互的物件（悬停抬起）单独一块画布，配一个透明热区。
- 三帧轮换的元素（烟、未完成的稿）只换线的种子，填色不变。
