# 首屏场景

> 做到“首屏画面”时读。达标样例：起手页首屏“合不拢的桥”（用户 2026-10-27：“这个标准可以了”）。

## 1. 构图：一整幅画，不是落地页

- 首屏是一张完整的手绘画或手抄报，标题是画的一部分。不套落地页模板：左边一块字、右边一张图、下面一排按钮。用户原话：“完全可以按照手抄报或者手绘画那种完全一体化的方式搞，不必要套用刻意生硬的landing模板，左侧字右侧图”。
- 标题放在画里空出来的地方，通常是天空、墙面或桌布。画给标题让位：彩铅在标题周围的椭圆里淡到约 18%，不是在标题下垫一块底色。
- 画面铺满屏宽，四边按噪声一截截淡回纸里（`edgeMask` + `fade`），不画框线、不切死边。手抄报花边画在画外。
- 主体放在中线附近，左右用两个有分量的东西互相平衡（演示页：两岸、两座半桥）。刻意画淡的元素不算分量。
- 手机改竖排：同一幅画重算几何（`sceneGeo(true)`），不是缩小桌面图。标题仍在天空里，主体落在下半屏。

用户否过的构图：

| 构图 | 用户原话 |
|---|---|
| 一张小卡片 + 一条线 + 一座小房子 | “首屏感觉设计感缺乏，过于简单” |
| 标题一侧重，另一侧只有淡元素 | “右侧太空，左侧太重” |

## 2. 景深：由远到近分层

一幅场景至少有三层，越远越淡、越冷、线越细：

| 层 | 演示页 | 画法 |
|---|---|---|
| 天 | 天色、太阳、云、鸟 | 彩铅长笔触缓斜铺开（角度 −.4、笔触长 32、密度 .036），成片留白；太阳和标题周围让出来 |
| 远景 | 两层山 | 远山蓝灰、近山灰绿；只在背光的坡上顺坡排线；轮廓线 .9–1 宽、.6–.7 透明；山脚用 `mist` 化进雾里 |
| 中景 | 两岸台地、松树、灌木 | 草地一条彩铅，前沿垂草；树用 `pine`、`bush`，越远越小 |
| 近景 | 崖壁、桥、河、卵石 | 线最粗（1.4–1.9）、细节最多；水面三帧轮换 |

- 远处的东西往一个消失点收拢（演示页：峡谷和河往远处变窄），画面就有深度。
- 雾和淡出用 `destination-out` 擦掉已画的墨，而不是盖一层白。

## 3. 比喻

- 首屏可以用比喻，但要强：一眼能看出“落差”。弱：越走越断的路。强：两岸各修一半却错开的桥；书上的饱满面包和烤盘里塌掉的面包；咬不上的齿轮。
- 先给用户两三个候选比喻，用户选了再画。
- 讲解图不用比喻，直接画关系（见 `diagrams.md`）。
- 一句红色手写批注加一个箭头，指向落差（演示页：“接不上”）。批注是可选项，最后由用户决定留不留。

## 4. 细节密度

精细来自四样东西，每个主要物件至少有三样：

| 来源 | 演示页里的例子 |
|---|---|
| 随形排线 | 背光坡顺坡排线；崖口顺崖边斜排线；岩层线下一段段阴影；云的底面排线 |
| 多层彩铅叠色 | 每道岩层一种土石色（7 色轮换）；背光面再压一层蓝灰；草地黄绿 |
| 结构细节 | 桁架斜杆、铆钉、桥面板缝、桥墩石块；灰岩层的竖缝、黄土层嵌卵石；石面小凹坑 |
| 周围的场景物 | 松树、灌木、草簇、岸边卵石、细瀑布、河面波纹、桥头小旗、鸟、太阳光芒 |

只靠线条抖动不算精细。

## 5. 大面积上色

一块大面（天、崖壁、地面）不要用一种颜色、一个角度铺满。所有笔触同角度时，大面会像在下雨。

- 把大面切成几层，每层一种颜色，笔触顺着层走（崖壁：层线略斜、笔触近水平 −.14）。
- 明暗另外叠一层：背光处再压一层冷色，草沿下压一道暗，往下越画越松。
- 天空最轻：长笔触、低密度、成片留白。
- 2× 裁图检查：大面上能看出层次和走向，看不出一道道平行斜线。

## 6. 动起来：灵动

用户要的是“整体更加灵动一些”，点击改成悬停。三类动效一起用：

| 类 | 演示页 | 数值 |
|---|---|---|
| 入场 | 天和山淡入 → 地和河 → 两座半桥从两岸往河心画出 → 小旗 → 桥头牌 → 批注 | 天 1.1 s；地 1 s，延迟 .35 s；半桥 `clip-path` 擦出 2 s，延迟 .9 / 1.05 s；批注延迟 3 s |
| 常驻 | 河水与小旗三帧轮换，鸟两帧，云左右慢飘 | 水 1.2 s 一轮；旗 .66 s；鸟 .72 s；云 24 s 往返 22 px |
| 悬停 | 悬停标题后半句或断口，断口处画出一个手画圈；悬停桥头牌，字逐字抖 | 圈擦出 .6 s；逐字抖 .42 s、错开 30 ms |

- 三帧轮换只换线的种子，填色不变；画面“沸腾”而不跳。
- Reduce Motion：关掉入场、常驻和抖动，三帧只留第一帧。
- 悬停对象放在画布上层的透明热区（`.sc-hit`），画布本身 `pointer-events:none`。

## 7. 物件写法

- 每个物件一个函数，传入位置和大小（`pine(c, x, y, sc, seed)` 以树根为原点）；线宽随大小缩放，但缩小的物件不要细到看不见（演示页远处的树按 .7–1.15 缩放）。
- 起手页 `index.html` 里有一个 `pl(cv, x0, y0, w, h)`：把一块画布放进场景、按场景逻辑坐标作画。换题材时照它写。
- 实心物体先 `under(c, poly)` 垫一块与页面同纹的纸，挡住后面的线，再在上面画。
- 自带纸底的画布用 `paperizeN`，不用 `paperize`（后者会擦成透明）。
- 每层一块画布：天、云、地、水、左桥、右桥、旗、批注、圈。要单独动的层才拆开。
- 场景参数集中在一个 `sceneGeo(vert)` 里（地平线、两岸、桥、太阳、云、鸟、树、石、批注位置），桌面和手机各一套。
