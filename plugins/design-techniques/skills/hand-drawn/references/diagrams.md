# 讲解图

> 做到“讲解图 / 教学图”时读。

## 1. 直接画关系，不用比喻

用户否过一次比喻（“用柜子表达这个逻辑不太易懂，比喻也不是很恰当”）。讲解图的读者要的是关系本身：

| 关系 | 画法 |
|---|---|
| 先后、推进 | 一根钢笔轴 + 手画箭头 + 圈出的编号 |
| 贯穿全程的维度 | 横穿轴的彩铅色带，末端收成箭头 |
| 越往后越深、越重要 | 排线逐档加层（level），彩铅密度随步数升 |
| 文字和图的对应 | 同色编码：条目圆点、条目名下的高亮、带名、色带用同一组颜色 |
| 分格 | 浅色虚线穿过色带切格，不画实框 |

首屏情绪画面可以用比喻（见 scenes.md），讲解图不用。

## 2. 版面坐标

- 图在逻辑坐标里画（横版 1000×600，竖版 360×680）。u 是推进方向，w 是横穿方向；横版 x=u，竖版 y=u，用 `XY(g,u,w)` 换算，同一套画法出两种版面。
- 画布宽度跟容器，`k = 容器宽 / W`，ctx 一次 setTransform(DPR·k)。

## 3. 悬停切层

- 底图一层（所有色带淡画），每条色带再画一层“激活版”叠加画布（`.ov`），切层只是换哪层可见，用 `clip-path` 擦出 .95s。
- 鼠标悬停列表或图上的带都切；触屏点按切；键盘 `focusin` 也切；翻页键逐层推进。
- 第一次进入视野时把当前层重放一次（IntersectionObserver）。

## 4. 手机

- 改竖版 geo：轴竖着走，带变成竖条，带名放顶上（取前两个字），图注放底部。
- 列表在上、图在下；图贴在卡纸上，卡纸边距收到 9。
