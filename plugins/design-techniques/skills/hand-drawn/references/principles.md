# 原理与审美

> 换题材、构思新画面、判断“为什么不好看”时读。这里写的是方法，不是某一幅画的配方。各节的“例”只用来说明，换题材时从原理重新推。

## 0. 三条底层原理

读者相信“这是人画给我看的”，靠下面三条。画面出问题时，先判断违反了哪一条。

### 0.1 材质一致：同一只手、同一套画具、同一张纸

- 页面上每一样看得见的东西都要像是同一个人、用同一套画具、画在同一张纸上。图、标题、正文、按钮、分隔线、翻页提示都算。
- 只要一样东西不属于这个世界，整页就露馅：系统字体、CSS 圆点、带阴影的圆角卡片、照片、“左栏文字加右栏插图”的网页版式。
- 技术上，一张纸面高度场驱动全部颗粒（`paper.md`）。版式上，问的是“这种纸面上的人会怎么排”：手抄报、笔记本、黑板、蓝图，而不是网页模板怎么排。
- 平庸：手绘插图塞进标准落地页。好：标题写在画里的天空上，翻页键也是手画的框。

### 0.2 结构准，笔触活

- 不完美只出现在笔触层：线的抖动、复描、断墨、颗粒、字的基线起伏。
- 结构层必须准：透视、比例、对齐、信息的位置和数值。结构歪了，读者读到的是“敷衍”，不是“手作”。
- 讲解图里，装饰不改变任何信息的位置。
- 抖动分档：结构线小，草稿感大，排线内部更小。“还没完成”用浅色、不上墨表达，不用乱线表达。

### 0.3 藏起机器的痕迹

- 程序画出来的东西容易露出规律：一大片同角度的平行线、处处相同的密度、等间距的重复、同一个形状复制多次、所有线一样粗。人眼对规律很敏感，一看就知道“是算出来的”。
- 人画画时，笔触跟着四样东西变：形体（方向）、材质（笔触形状）、明暗（密度）、注意力（细节多少）。
- 每一处随机都要回答“为什么在这里不同”。答不出来的随机，就是噪声。

## 1. 一幅画只说一件事

- 动笔前写一句话：读者看 3 秒，要明白什么。
- 画分两类，画法不同：

| 类 | 读者要的 | 画法 |
|---|---|---|
| 情绪画面（首屏、章节页） | 一种感受：落差、冲突、期待、转变 | 视觉比喻 |
| 讲解图 | 一个关系：先后、分支、对比、包含、多少 | 直接画关系本身（`diagrams.md`），不用比喻 |

- 视觉比喻有三种构造，编辑插画里最常用：

| 构造 | 做法 | 例 |
|---|---|---|
| 并置 | 两个本该一样的东西放在一起，差别就是要说的话 | 配方书上的饱满面包，旁边是烤盘里塌掉的那个 |
| 断开 | 一个本该连上的东西没连上，断口就是要说的话 | 两岸各修半座桥，在河心错开 |
| 融合 | 两个东西合成一个，合出来的新东西就是要说的话 | 钥匙的齿是一排城市天际线 |

- 好比喻有张力，一眼能看出落差，不需要解释。弱比喻只有一个元素，或者要读者先想一下（一条越走越断的路）。
- 先列三个候选，每个写一句“为什么能说清这件事”，推荐一个，让用户定。

## 2. 构图与视觉重量

- 视觉重量由四样东西决定，重要性依次是：明度对比、细节密度、饱和度、面积。刻意画淡的东西几乎没有重量，面积再大也一样。
- 按概念选平衡方式：

| 方式 | 适合 | 做法 |
|---|---|---|
| 对峙 | 冲突、落差、两方 | 两个分量相当的主体左右相对，焦点在两者之间 |
| 对角 | 旅程、推进、变化 | 主体与标题对角，或用一条斜线（路、河、光）把眼睛从一角引到另一角 |
| 中心 | 单一对象、聚焦 | 一个主体居中，四周留白，环境只在边上点到 |

- 焦点放在概念发生的地方：断口、交叉点、变化点。
- 版式语法来自题材的纸面，不来自网页模板：

| 纸面 | 版式语法 |
|---|---|
| 手抄报 | 大标题横在画里，四周花边，图文穿插，角上贴胶带 |
| 野外笔记本 | 画为主，手写批注散在旁边，引线指向细部，贴票根 |
| 黑板 | 中心板书，四周推导，粉笔框出重点 |
| 蓝图 | 主视图居中，剖面与尺寸线在旁，标题栏在右下 |
| 配方卡 | 卡片标题在上，步骤编号，食材画在边上 |

## 3. 明度结构

- 先定 3 到 4 个明度：纸白、浅、中、深。纸本身就是最亮的，不另画白。
- 最深和最亮挨在一起的地方，眼睛最先去。把这个地方放在焦点上。深色集中在焦点附近，外围用浅和中。
- 标题放在安静的浅区。
- 检查：把截图模糊到看不清线，或缩到 200 px 宽，只看明暗块。主体是否清楚？左右是否平衡？标题是否在浅区？

## 4. 细节分布：焦点细，外围点到为止

- 细节密度随离焦点的距离递减：
  - 焦点：结构细节、多层叠色、随形排线。
  - 中景：轮廓加一层颜色、少量排线。
  - 外围：画一小片纹理，让眼睛补全其余部分，然后淡回纸里。钢笔插画一直这么做。
- 画面四边不画死。按噪声一截截淡回纸里，上沿淡得更慢。纸上的画不需要边框。
- “过于简单”和“太满太乱”是同一个问题的两头。前者整体细节不够，后者细节没有分布。检查时分出焦点区、过渡区、留白区，三个区都要有。
- 细节要来自结构，不来自抖动：零件、接缝、层理、纹路、物件周围的环境。只把线画抖，不算精细。

## 5. 空间与景深

- 有空间的画面至少分远、中、近三层。
- 空气透视：越远越淡、越冷、线越细、细节越少、对比越低；越近越暖、越实、线越粗。
- 其他深度线索：

| 线索 | 做法 |
|---|---|
| 遮挡 | 近的挡住远的。实心物体先垫一块同纹纸（`under`），再画 |
| 汇聚 | 远处的线收向一个消失点 |
| 大小 | 同类物件越远越小 |
| 雾 | 远景脚下往下擦淡（`mist`） |

- 讲解图也有层次：卡纸贴在纸上有影子，激活层叠在底层上。

## 6. 笔触语言

- 线分三级，越往下越细越淡：外轮廓、结构线（内部转折）、纹理与排线。
- 排线方向顺着形体走：圆柱顺长轴，坡面顺坡，弧面顺弧，竖面竖排。不用一个角度斜排到底。
- 笔触形状跟着材质变：

| 材质 | 笔触 |
|---|---|
| 天空、雾 | 长、缓斜、低密度，成片留白 |
| 岩石、土层 | 顺层理近水平，每层一种颜色，层线断续 |
| 水 | 横向短线和波纹 |
| 草、植物 | 竖向短笔，成簇 |
| 木头 | 顺木纹的长线，节疤处绕开 |
| 金属 | 干净直线，硬边，高光处留白 |
| 布料 | 顺褶皱的弧线 |
| 面包、陶器 | 顺弧面的短弧，焦色压在边缘 |

- 分工：彩铅给颜色，排线给明暗。明暗靠笔触密度，不靠填色块。

## 7. 颜色

- 限定色板：一种墨色（纸色的暗端，同一色相）加 3 到 4 种彩铅色。
- 每种颜色绑定一个意思，全页不变。图里的颜色和文字的颜色对应：关键词是什么色，图里对应的部分就是什么色。
- 强调色只用在一两处，例如一个红色批注、一个手画圈。到处都是强调，就没有强调。
- 冷暖做深度：远冷近暖。

## 8. 字图一体

- 标题是画的一部分。它放在画里本来就空的地方：天空、墙面、桌布、黑板的空处。画在标题周围让出一圈淡处，不在字下面垫底色块。
- 字和画出自同一只手：手写字体，逐字基线和倾角微变；下划线、圈、箭头都手画。
- 标签写在物件上或物件旁边，例如桥头牌、便利贴、价签，不另做图例。
- 可读性不让步：正文对比度 ≥ 4.5:1，标题不被纹理吃掉。

## 9. 动：让画活着，不是表演

三层动效，各管一件事：

| 层 | 作用 | 做法 | 分寸 |
|---|---|---|---|
| 入场 | 讲画的顺序 | 按“世界 → 主体 → 冲突 → 批注”逐层画出或擦出，像有人正在纸上画 | 总长 3 到 4 秒，只播一次 |
| 常驻 | 让画活着 | 线条轻微“沸腾”（三帧只换随机种子，传统动画叫 line boil）；本来会动的东西按自己的物理动：水流、旗飘、鸟飞、云移、烟升 | 幅度小、节奏慢；不会动的东西不动 |
| 响应 | 回应读者 | 悬停在概念点上：手画圈圈出关键处、字抖一下、图换一层 | 只放在概念点和可交互的东西上；触屏改点按 |

- Reduce Motion：三层全关，三帧只留第一帧，入场直接显示画完的样子。

## 10. 从用户的话找原则

用户的评价多半是感受。先翻成原则，再改：

| 用户说 | 多半是 | 先查 |
|---|---|---|
| “太简单”“没设计感” | 概念弱，或整体细节不够 | 第 1、4 节 |
| “丑”“没质感”“像贴上去的” | 材质不一致 | 第 0.1 节 |
| “潦草”“乱” | 结构不准，或细节没有分布 | 第 0.2、4 节 |
| “一边重一边空” | 视觉重量失衡 | 第 2、3 节 |
| “像模板”“生硬” | 版式来自网页，不来自纸面 | 第 0.1、2 节 |
| “看不懂”“比喻不恰当” | 讲解图用了比喻，或比喻要解释 | 第 1 节 |
| “呆”“死板” | 缺常驻和响应动效 | 第 9 节 |
| “假”“像机器做的” | 机器痕迹 | 第 0.3 节 |
