# 手绘风格化 · hand-drawn

效果：页面像画在一张有颗粒的纸上，图是钢笔勾线、彩铅上色、排线出明暗，字是手写的，悬停时字会“抖一下”、图会换一层。
本质：一张纸面高度场驱动全部质感（纸纹、彩铅只落在纸齿上、墨在深坑里断开、大字缺墨），画具全用 Canvas2D 代码画，所以颗粒对得上、可交互、可改。
开工前先看这张图：`${CLAUDE_SKILL_DIR}/showcase/cover.webp`。

## 1. 何时用、何时不用

| 用 | 不用 |
|---|---|
| 讲课页、讲解图：要把一个关系“画给人看” | 需要照片、真实产品图的页（手绘会显得假） |
| 首屏要有温度、像手作，而不是模板页 | 数据要精确读数（排线和抖动会干扰读值） |
| 用户在意“是代码画的，不是生图”，要能悬停、切层、改字 | 只要一张静态图：生图更快，不必搭画具 |

## 2. 先想清楚风格化什么

手法 = **一种模拟的介质**（纸 + 画具 + 字）**套在一个题材上**。先从题材出发，回答三个问题，再选变体：

1. 这个题材在现实里是在什么“纸面”上被画出来的？（课堂 → 笔记本、黑板；工程 → 蓝图；厨房 → 配方卡；旅行 → 手账）
2. 那个场合的人用什么笔？（钢笔、彩铅、马克笔、粉笔、水彩、炭笔、丝网两色）
3. 页面要讲的“关系”是什么？讲解图直接画关系（轴、色带、同色编码），首屏情绪画面可以用比喻，但比喻要强、要画成一整幅精细场景。

## 3. 风格规范（已验证版本的数值）

这些是**锚点，不是配方**。换题材时：先定纸色和墨色（墨色取纸色的暗端，带同一色相），再按画面尺度缩放线宽和笔触长度，最后在 2× 裁图上看颗粒是否“落在纸上”。

| 项 | 数值 |
|---|---|
| 纸 | `#f1e9d6`；高度场三层 200 / 64 / 16 格，权重 .46 / .26 / .12，白噪声 .16；平铺块 512 px；纤维 170 条、杂点 28 个 |
| 纸齿（彩铅进不去） | h < .47 处，软边 .17；彩铅 tooth 强度 .45–.65 |
| 墨缺口 | h < .28 处，软边 .12；`paperize` 强度 .55（大物件 .3–.4） |
| 大字遮罩 | 只在 h < .22 的深坑处，最多去掉 30% |
| 墨 | 暖黑 `#2b2420`；钢笔主线 1.3 + 复描 .5 倍宽、.45 透明；抖动 jit .8（干净物件 .3–.4） |
| 彩铅 | 角度 −1.08 rad 统一；笔触长 13、宽 1.6；密度 .12（淡）– .28（实）每平方单位 |
| 排线 | 四层：顺向 thr .16 / .42，交叉 ±.5 rad thr .6 / .78；线距 5.4–5.6；线宽 .7–.8 |
| 四色 | 金 `#e0a84f` / 绿 `#86b596` / 橙红 `#e39478` / 蓝 `#86a6d8`，各配一个深色字色 |
| 字 | 标题霞鹜漫黑（记号笔），正文小赖（细钢笔）；逐字基线 ±.035em、倾角 ±1.6° |
| 动效 | 逐字抖 .42s、steps(1)、错开 30ms；三帧轮换 1.05s 一轮；切层擦出 .95s；卡片抬起 .45s 回弹 |
| 手抄报 | 花边边距桌面 20、手机 6；内圈点距 9；四角星；页眉胶带半透明金色 |

状态：纸、颗粒、字体用户已认可（“很好了”）；手抄报花边、悬停切层和逐字抖动已交付、用户暂无意见；首屏整幅场景是最新一版，待用户看。

正向做法：

- 精细来自**细节密度**：随形排线、多层彩铅叠色、物件的结构细节（割口、扎口、窗格、把手）、物件周围的场景。只靠线条抖动不算精细。
- 首屏是**一整幅场景**，铺满屏宽，标题放在场景的留白里；用一个深色主体平衡标题。
- “还没做到”的东西用浅色、不上墨表达，线仍然干净（抖动 .3，不出头）。

## 4. SOP

1. 读题材，按第 2 节三问写出：纸、画具、版式、要讲的关系。讲解图写“轴是什么、色带是什么、哪些颜色对应哪些文字”。
2. 先规划内容并和用户确定（每屏讲什么、图里有什么），再动手。用户要求过“不要随便跳步”。
3. 复制 `${CLAUDE_SKILL_DIR}/templates/starter/` 到项目里，改 `STEPS`、`ROWS`、文案和两个 geo 函数。
4. 跑字体脚本（见第 5 节）生成子集。改了任何文字都重跑。
5. **首屏试样先给用户看**（首屏 + 一张图），用可批注的预览链接。按反馈改，再做整页。已验证的那次就是这样走了四轮。
6. 截图自检：1440×900 与 390 宽（走 iframe 包装）、悬停后一张、2× 裁图看颗粒。每张图亲眼看。
7. 检查 `prefers-reduced-motion`、键盘聚焦切层、触屏点按切层。

## 5. 起手代码

| 文件 | 用途 | 怎么用 |
|---|---|---|
| `templates/starter/hand-drawn.js` | 画具包，全局 `HandDrawn`，无依赖 | 阅读 + 引入。`HandDrawn.init(opts)` 生成纸并写 CSS 变量 `--paper-img`、`--ink-mask` |
| `templates/starter/index.html` | 演示页：首屏场景 + 教学图 | 运行。复制后改内容；`?p=2`、`?row=0..3`、`?only=2` 用于截图 |
| `templates/starter/fonts/` | 两款字体子集 + OFL 许可证 | 随页面发布，许可证文件一起带上 |
| `scripts/fonts.sh` | 下载字体（缺时）+ 按页面取字子集化 | 运行：`FONT_SRC=<已有原件目录> bash ${CLAUDE_SKILL_DIR}/scripts/fonts.sh <输出目录> <页面.html> [更多 .js]` |

画具 API（全部在逻辑坐标里画，返回点列的函数交给 `pen` 画）：

| 函数 | 作用 |
|---|---|
| `pen(c, pts, {w, jit, alpha, color, seed, closed})` | 钢笔：主线 + 复描，噪声摆动 |
| `pencil(c, clip, box, {color, angle, len, w, density, alpha(x,y), op, tooth, seed})` | 彩铅：同角度短笔触，按纸齿打颗粒，multiply 落下 |
| `hatch(c, clip, box, {angle, sp, thr, w, alpha, tone(x,y,lr), level(x,y,lr)})` | 墨线排线；配合 `HATCH_LAYERS` 四层叠出深浅 |
| `ring` / `rbox` / `tape` / `sparkle` / `paperCard` / `frame` / `tagTape` / `fadeDash` | 手画圈、圆角框、胶带、星、卡纸、手抄报花边、页眉胶带、越走越断的线 |
| `paperize(cv, a)` | 画完一层后按纸的深坑擦掉一些墨 |
| `fitTo` / `place` / `placeIn` | 画布铺满元素 / 放在父元素坐标 / 按图的逻辑坐标放 |
| `handset(el, seed, amp)` / `label(box, W, H, x, y, text, o)` / `fontsReady(specs)` | HTML 逐字手写排；图内标签；字体显式加载 |

## 6. 载体与降级

| 载体 | 表现 |
|---|---|
| 桌面 / 投屏 | 两屏整屏吸附，方向键翻页并逐层切换 |
| 手机 | 场景和教学图改竖排（`geo(true)`），花边边距 6；触屏点按切层，提示改“往下滑” |
| Reduce Motion | 关闭入场、抖动、擦出；烟只留第一帧 |
| 无 JS | 只剩纸色底和楷体回退的文字，图不出现。要保底就在 `<figure>` 里放一句文字说明 |
| 缺手写字体 | 回退楷体；质感降一档，但版式不坏 |

## 7. 踩坑（来自真实反馈）

1. **讲解图用比喻** → 用户：“用柜子表达这个逻辑不太易懂，比喻也不是很恰当”。原因：比喻要读者先翻译一次。改法：直接画关系。平庸：6×4 的标本柜；好：六步是时间轴，四条线是横穿全程的彩铅色带，越往后排线越深，左侧条目圆点与色带同色。
2. **质感不够手绘** → 用户：“字体以及其他组件，整体搞成手绘风格……包括底层的纸质感、颗粒感”。原因：系统字和 CSS 圆点让纸上的画显得像贴上去的。改法：手写字体逐字抖动；纸、彩铅、墨缺口、大字遮罩取自同一张高度场；圆点改手画圈加彩铅。
3. **终点画得潦草** → 用户：“小房子有些过于潦草了”。原因：线条两头出头、抖动 .9、三帧每帧都大变。改法：未完成的东西用浅色、不上墨表达，线不出头、抖动 .3，屋顶一层较实的石墨、墙很浅，加窗格和门把；三帧只换线的种子。潦草不等于草稿感。
4. **左重右空** → 用户：“整体的布局很奇怪，右侧太空，左侧太重”。原因：刻意画淡的元素不算分量，深色全压在一边。改法：用一个深色主体平衡标题。平庸：标题左、淡淡的目标物右；好：主体物件与标题对角放，淡元素只做陪衬。
5. **首屏太简单** → 用户：“首屏感觉设计感缺乏，过于简单，手绘的部分可以搞得精细精美一些，这个比喻可以改换一下，再考虑考虑”。原因：一张纸、一条线、一座房子的小插画撑不起首屏；弱比喻（越走越断的路）不够有力。改法：首屏画一整幅铺满屏宽的钢笔场景，标题落在留白里；细节密度来自随形排线、多层彩铅、结构细节和周围的场景物；比喻要强（例如两岸各修一半却错开的桥、咬不上的齿轮）。本页演示版改成“书上的饱满面包 → 烤盘里塌掉的面包”一整张桌面静物。注意与第 1 条分开：讲解图直接画关系，首屏情绪画面可以用比喻。
6. **装饰画布错位** → 无头截图时视口高度会变（布局 813，截图 900），按整屏坐标画的下划线压到字上。改法：装饰画布挂在文字所在容器里；ResizeObserver 同时观察标题和整屏；桌面截图也走 iframe。
7. **字体没加载就画了** → `document.fonts.ready` 可能先返回。改法：`fontsReady([["HD Marker","样例字"]])` 显式加载再画；canvas 的 `fillText` 同样要等。
8. **multiply 不会变亮、压不到纸** → 浅色卡纸用普通混合加一层 `rgba(255,252,244,.42)`；父元素有 z-index / opacity<1 / mask / clip-path 就成了隔离组，multiply 只和透明底混。容器保持 `z-index:auto`，卡纸 `z-index:-1` 垫后面。
9. **标题像镂空模板字** → 墨缺口遮罩太强。最多去掉 30%，且只在 h<.22 的深坑处。
10. **悬停被旋转画布挡住** → 旋转后的外接框盖住标题。画布 `pointer-events:none`，另放一个同样旋转的透明热区，用 `.hit:hover + .card` 触发。

布局与换行的细坑见 `references/layout-pitfalls.md`。
