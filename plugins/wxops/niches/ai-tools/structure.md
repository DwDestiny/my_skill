# AI 工具赛道 · 结构契约

写作三件套之二。draft-writer 按本契约搭骨架，style-auditor 按本契约验结构。**本契约管结构，persona.md 管口吻**——两边冲突时，合规红线以 persona 为准，结构分歧以本契约为准。

## 全文体通用规则

1. **开头 100 字定生死**：第一句必须是「数字砸脸 / 第三方背书 / 情绪宣告」三选一。严禁「大家好」「今天聊聊」「相信很多朋友」式开头——读者在"看一看"信息流里只给你一屏的机会。
2. **小标题分层**：正文每 300-500 字一个小标题，方便跳读；小标题本身要携带信息（读完所有小标题 = 读完文章大纲）。
3. **事实纪律**：每个具体数字、结论、引用都必须来自证据包（evidence.md）。证据包里没有的，要么回去补包，要么删掉论点——不许现编。
4. **收尾三件**：结论收拢（一段说清"所以呢"）+ 下一步承诺（下篇写什么/项目进展在哪跟）+ 账号引导（按 persona.md 变现钩子边界执行，不越线）。
5. **AI 味清除**：交稿前自查——排比堆砌、"总的来说/综上所述"、每段等长、无一手细节，都是 AI 味重灾区。有一手数据和具体踩坑细节是最好的除味剂。

## 文体骨架（按稿选用）

### 测评体（适用题材：模型发布/能力解读、泛 AI 热点/效率工具）

- **骨架**：钩子（一句话结论先行）→ 我为什么测它 → 实测过程与数据 → 横向对比（可选）→ 谁该用谁别用 → 收尾三件
- **必备模块**：实测数据段（自己跑出来的数字，标注测试环境与日期）；「谁别用」段（只说好话的测评没有信任价值）
- **字数**：2000-3500 字
- **翻车点**：把官方 changelog 复述一遍当测评；结论骑墙（"各有千秋"= 没测出东西）

### 教程体（适用题材：AI 编程/Agent 工作流、泛 AI 热点/效率工具）

- **骨架**：钩子（做完能得到什么，带数字）→ 前置条件清单 → 分步操作（每步一个小标题 + 预期结果）→ 常见坑与排错 → 效果验证 → 收尾三件
- **必备模块**：前置条件（版本/费用/权限，让读者动手前知道门槛）；「常见坑」段（教程的差异化价值就在坑上）
- **字数**：1500-3000 字；步骤宁少勿糊，每步都要可独立验证
- **翻车点**：步骤跳跃（"然后配置一下就好了"）；没写自己踩的坑（说明没真跑过）

### 观点体（适用题材：风险/账号/额度焦虑、产品/副业/商业化）

- **骨架**：钩子（反常识断言或风险预警）→ 现象与证据 → 我的判断与推理链 → 反方观点与我的回应 → 对读者意味着什么 → 收尾三件
- **必备模块**：推理链（从证据到判断的每一步都摆出来，让读者可以在任何一步反驳你）；「对你意味着什么」段（观点要落到读者的下一步动作）
- **字数**：1500-2500 字
- **翻车点**：只有情绪没有证据链；立场随流量摇摆（前后文章观点打架又不解释）

### 复盘账本体（适用题材：产品/副业/商业化）

- **骨架**：钩子（核心数字先行：赚了/亏了/花了多少）→ 账本明细（表格）→ 数字背后的三个判断 → 下阶段计划（可验证的承诺）→ 收尾三件
- **必备模块**：账本表（收入/支出/时间投入，能公开的都公开）；「我判断错了什么」段（只晒赢的复盘是广告）
- **字数**：1500-2500 字
- **翻车点**：数字四舍五入到看不出真实性；把运气归因成方法论

### 快讯体（适用题材：价格/额度/羊毛情报、风险/账号/额度焦虑、模型发布/能力解读）

- **骨架**：钩子（发生了什么 + 影响谁）→ 事实核（时间/来源/变化点，引证据包）→ 该做什么（分人群给动作）→ 时效声明（截至何时有效）
- **必备模块**：时效声明（价格/额度/政策类信息必须标注"截至 YYYY-MM-DD"）；动作建议按人群拆分（重度用户/轻度用户/观望者）
- **字数**：600-1200 字，快讯拼的是快和准，不是厚
- **翻车点**：转述二手消息不核源头；标题比事实激烈（标题党失实是平台红线）

## 题材 × 文体速查

| 风险/账号/额度焦虑 | 快讯体 | 观点体 |

## 标题公式衔接

标题候选由 title-smith 按 niche.json 的 `title_patterns` 八式（风险损失型/价格福利型/模型发布型/对比替代型/教程清单型/疑问反常识型/工作流案例型/普通资讯型）生成，正文文体与标题公式要匹配：教程体配教程清单型、复盘账本体配工作流案例型或疑问反常识型——标题承诺什么，正文就得兑现什么。
