# UI 设计系统

本阶段可由用户直接调用，也可由 [$ui-delivery](../ui-delivery/SKILL.md) 串联。使用本阶段实际输入即可；缺少上游文件时写明假设与限制，不伪造上游已完成。

- **目标**：把获选方向图或已有系统转为完整、可执行的视觉规格与公共组件母版，供逐屏设计和实现复用。
- **最小输入**：获授权的视觉方向或用户指定的现有令牌/组件库，及需要覆盖的页面/状态；可从现有项目文件直接盘点。
- **输出**：design-system.md、tokens.json、component-inventory.json；覆盖颜色、字阶、间距、布局、组件状态和资产复用，区分确认值、提案值与图片推断值。

## 工作要求

把视觉方向或已有系统转为页面和实现可复用的语义规则。按 [阶段工作流](references/workflow.md) 执行。只有完整套件工作区才登记 stage.json 与 snapshot.json。
整套页面交付时，此阶段的关键规格和公共组件母版须先获确认并冻结版本，才进入逐屏高保真与实现；不要用后来的实现截图反写设计基线。具体审查见 [视觉一致性交接](../ui-delivery/references/visual-consistency.md)。独立调用时按本阶段实际输入和范围处理。

## 失败回退

关键品牌约束不明时记录阻塞或待定，不猜定品牌令牌。

## 验收标准

页面需求可映射到完整令牌、公共组件及其版本和复用页；状态样式齐备；图片推断值和提案值未伪装为已授权的精确规格。
